## 2. 线下实际 JSON 协议与消费者（冻结包未含，必须原样保护）

### 2.1 协议生成器：`offlineOutProto`（`prompt-engine.js:1509-1553`）

产出结构：`{paras:[{type,text,trans?}], suggests:[], envUpdate:{clockTime}, scene?}`。
`trans` 段仅在 `transAsked(charId)` 为真时追加（`:1531-1537`）；`scene` 段仅在 `session.pendingSetup` 时追加（`:1544-1550`）。

**协议侧硬事实（迁移时一条都不能动）：**
1. `type` 只有 `dialogue` / 其他→`prose` 两个值（`:1692`）——**闭合集**；
2. `trans` **只能在 dialogue 段**，且**不能进 `text`**（会被 `parasText` 拼进历史）；
3. `suggests` 消费者硬截 3 条（`:1705`），提示词里写的是「0~3 条」（`:1538-1540`）——**数字一致**；
4. `envUpdate` 只在 `n.timeAdvance` 开时存在（`:1541-1543`），关闭时**固定省略**；
5. `scene` 只在 `pendingSetup` 那一轮出现；
6. 解析失败**不崩溃**，降级为单条 prose（`:1714-1716`）；
7. **JSON 围栏 + 前后多余文字**都要能剥（`:1679-1687`）。

⇒ 冻结包 B/P/L/N/S2 **完全不含**输出协议，这是**正确**的（与线上 `BT_C05_ONLINE` 同分工）。线下需要一份**平行的** `BT_C05_OFFLINE`，但**必须由现有 `offlineOutProto` 演化而来，不能另写**。
