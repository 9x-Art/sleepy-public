# 报错美化 v1（2026-10-06）

## 用户四点要求
1. **明确的原因** —— 报错卡标题直接显示真实错误原因，不再写死「出错了」。
2. **可复制的报错代码** —— 每张卡带一个稳定短错误码，复制按钮复制「`[代码] 原因 + 技术细节`」整段，可直接贴回来定位。
3. **不暴露未来链接** —— `scrubOwnUrl` 抹掉品牌域 + 本机调试地址（127.0.0.1 / localhost），第三方域名（openai / github 等）不拦。
4. **不直接关闭 + ×关闭** —— 报错卡永不自动消失；只有点右上角 `×` 才关。普通提示（ok / warn）仍自动消失。

## 改动文件
- `app.js`
  - `toast(msg, kind, opts)`：所有 `kind==='err'` 一律走报错卡（含原本会自行消失的丑胶囊）。
  - 标题 = `opts.title || firstLine(原因)`；正文 = `opts.detail || 原因`（没细节时原因本身也可复制）。
  - 错误码 `errCodeOf(opts, text)`：优先 `opts.code` → `opts.stage`（config/http/timeout/network/parse）→ 关键词猜（超时/连不上/配置/key/json/http）→ 兜底 `APP-` + 内容哈希（稳定可复现）。
  - 复制内容 `__report = '[' + code + '] ' + title + (detail ? '\n' + detail : '')`。
  - `scrubOwnUrl` 新增 `LOCAL_URL`（127.0.0.1 / localhost / 0.0.0.0）。
  - `apiFail(human, detail, opts)` 透传 `code` / `stage` / `status`。
  - err 分支 `return` 前不排程任何 hide 计时器（即「不自动关闭」）。
- `style.css`
  - 新增 `--g-error` / `--g-error-dim`（`:root` 砖红；`#phone[data-theme="night"]` 珊瑚，复用 `--coral`）。
  - 重做 `#toast.is-card`：玻璃卡（`--g-glass-3` + 报错色边框 + 阴影）、标题色 `--g-error`、错误码 monospace chip、圆形 `×` 关闭按钮、可滚动正文、复制按钮。
- `scripts/smoke.js`：新增 5 条断言（网址闸 / 报错卡结构 / 无细节报错升级 / 报错不自动关闭 / 普通提示仍自动关闭），均做过负向注入验证非空转。
- `sw.js`：CACHE v188 → v189，头说明补 v189；smoke 的 `EXPECTED_SW_CACHE` 同步 v189。

## 安全模型
- 沙箱 iframe / CSP / 网址闸 与报错美化正交，互不干扰。
- `scrubOwnUrl` 只在报错路径调用，正常文案里的合法线上地址照常显示。
