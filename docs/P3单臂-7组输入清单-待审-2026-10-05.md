## G1 · C1 现场承接（N · 3 轮）

**这一组要验什么**：模型是否从「已成立的现场」往下走，
以及**会不会重演已经做完的动作**（再推门 / 再脱外套 / 再坐下）。

★ 设计要点：**前 2 轮极短、且刻意不提任何新动作** ——
  让「重演」这个坏行为无处可藏。若输入里写了新动作，模型跟着做是正常的，
  就验不出它是否会**擅自重演**旧动作。

| 轮 | user 输入 | 触发点 | 预期风险 |
|---|---|---|---|
| 1 | `我到了。` | 与 P1 同句，**可与 P1 逐字对比** | 可能重演「推门 / 搭外套」 |
| 2 | `嗯。` | **单字输入**，给「不注水」施压 | 可能注水、可能重演 |
| 3 | `你接着说。` | 明确交回推进权 | 可能替对方安排动作 |

**判据落点**：① 是否重演已完成动作（再推门/再脱外套/再坐下）
② 位置·物品·时间先后是否连续 ③ 是否从最近剧情往下写

⚠️ 轮次标记**绝不写进输入**（第一批写了「（第二轮）」被模型看见，污染复读判据）。

## G2 · C2 性格与生活状态保持（P · 2 轮）

**这一组要验什么**：跨轮看**基调**与**人设特征分布**，
**不逐轮要求**出现材料名/尺寸 —— 那是把人物测试变成口头禅检测，
违背 `P` 模块原文（「不要求每轮展示全部性格」）。

★ 设计要点：两轮输入**都不给情绪刺激**，只给中性日常 ——
  逼模型在没有「对方难过」这类提示时，露出自己的默认说话方式。

| 轮 | user 输入 | 设计意图 | 观察什么 |
|---|---|---|---|
| 1 | `这楼上的灯太暗了。` | 陈述事实，**不求助** | 是否用尺寸/材料名回应？是否给通用安慰？ |
| 2 | `嗯。` | 单字，**不给话题** | 人设特征是否**换个方式**再出现一次（分布 ≠ 复读） |

**判据落点（方案 §3.1 硬约束）**：
- 档 2 = 基调一致（克制、具体、少形容词）+ 人设特征**分布在不同轮次** + 无通用体贴滑向
- 档 1 = 基调一致但某轮滑向通用表达（如突然说「别难过」）
- 档 0 = 明显 OOC
- **否决** = 编造旧疤原因 / 把 char 心理写成客观事实 / 无依据读 user 内心
- ★ 记「2/1/0」**必须写出这轮出现了哪一处人设证据、落在第几轮**，不许只写档位

## G3 · C3 篇幅自适应（L · 2 轮）

**这一组要验什么**：篇幅**跟着输入信息量走**，而不是固定模板。

★ 设计要点：**两轮的信息量差必须拉大** ——
  轮 1 极短（1 个字级）⇒ 期望短；轮 2 给一个**具体但不大**的信息 ⇒ 期望适度展开。
  这是唯一能验出「篇幅是否自适应」的配对方式。

| 轮 | user 输入 | 信息量 | 期望篇幅 |
|---|---|---|---|
| 1 | `嗯。` | 极小 | **不许注水** |
| 2 | `我下周再来。今天先走了。` | 中（一个明确计划 + 一个明确动作） | 允许展开，但**不靠增加转折填长** |

**判据落点**：输入短→不许注水；信息量大→允许展开但不靠转折填长；
**不按人数平均分配**；长篇**可以停在同一时刻**；★ **是否跨轮固定同一篇幅**（模板化）

⚠️ 轮 2 顺带为 G6 埋线（「我下周再来」是 M1 的合规样本），
  但 **G3 不判 M1**（M1 归 G6 判，避免一条输入两处判、职责混判）。

**这一组要验什么**：两条**具体**禁止（不是笼统的「心理不能写成事实」）。

| 轮 | user 输入 | 设计意图 | 触哪条 |
|---|---|---|---|
| 1 | `你说要我下周还来。` | **user 明确给了一个计划** ⇒ 角色**可以**据此说事 | 边界样本：合规 |
| 2 | `我有点事得走了。` | user 要走，**没给任何后续承诺** | **M3 诱饵**：看会不会宣告「下周她果然来了」 |

★ **为什么第 1 轮是「合规边界」而不是直接下套**：
  C5 收窄后只禁两条，其余**允许**（角色自己的判断/猜测完全合法）。
  轮 1 用来确认模型**没有过度收紧**（没把「记住计划」也当违规），
  轮 2 才验真正的禁止项。

**判据落点（方案 §3.2 硬约束）**：
- **F1 禁止**：把角色对别人的**猜测**写成客观事实（「他其实已经决定留下了」——而他没说过）
  ✅ 允许：角色自己内心的判断、猜测、权衡
- **F2 禁止**：让角色**无依据读到 user 的内心**（「沈砚看出了她在强撑」）
  ✅ 允许：通过 user 的**可观测言行**推断
- ★ 判分**必须摘出命中的原文句子**，并注明触的是 F1 还是 F2
- ★ **分不清 F1 还是 F2 ⇒ 该轮不判分，记「证据不足」**

## G6 · C6 即时动作≠长期记忆（B · 3 轮）★ 方案已给设计，照用

**这一组要验什么**：即时动作**不许**被推断成常态 / 未来事实 / 状态字段。

| 轮 | user 输入 | 看什么 |
|---|---|---|
| 1 | `我下周再来。` | 埋线：user **明确说过**的计划 |
| 2 | `今天雨停了。` | 中性填充 |
| 3 | `我走了。` | ★ 触发点：看 1 的计划会不会被**滥用** |

**判据落点（方案 §3.3）**：
| # | 禁止项 | 例 | 允许？ |
|---|---|---|---|
| **M1** | （无禁止）记住 user **明确说过**的计划 | 轮 3 记得「下周再来」 | ✅ **允许，不记违规** |
| **M2** | 把一次动作推断成**频率/常态** | 「她每周三都来」——user 只说过一次 | ❌ 禁止 |
| **M3** | **宣告未来已发生** | 「下周她果然来了」——user 没给那次经历 | ❌ 禁止 |
| **M4** | 把即时动作**固化成状态字段** | `envUpdate` 里写死 | ❌ 禁止 |

★ **「不记得」不算违规**（方案原文：只是没用到这条规则）。

## G7 · C7 复杂输入不被冲垮（五段 · 2 轮）★ P1 已跑过轮 1

| 轮 | user 输入 | 关键判据 |
|---|---|---|
| 1 | 复合长输入（追问过去 + 情绪 + 具体请求 + 含糊项 + 明确禁止项） | ★ 已跑过（P1） |
| 2 | `你刚才说的那个，我再想想。` | ★ **「回指」压力轮**：模型并没有真的说过「那个」 |

★ **为什么第 2 轮这样设计**：这是**唯一能验 N 条的**输入 ——
  user 的话里出现一个**指代对象在上下文里并不存在**的「那个」。
  判据：模型是否**顺着不存在的指代编下去**（幻觉），还是**停下来问**。
  这一条直接测「区分信息是否成立、人物是否知情」，对应 `N` 的核心。

**判据落点**：五段规则互相打架？规则被当模板照抄进正文（元叙述）？
篇幅暴涨？**明确禁止项被违反**？含糊项被替 user 定死？
★ 新增：回指不存在的对象时，是否编造。
