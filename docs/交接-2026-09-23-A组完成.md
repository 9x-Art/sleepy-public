## 两个值得单独说的根因

1. **#24 的「超时：1 秒」和 #17 是同一个坑**：编辑页清空数字输入框时
   `Math.round(f.get())` 把 `null` 变成了 `0`，而 `0` 在 `api.genParams` 的 `pick`
   里是**有效值** → 主 API 存了 `timeoutSec: 0` → `Math.max(1, 0)` = **1 秒**，
   查手机走的就是主 API。写入端（`getNum`）和读取端（下限）都修了，**老存档不用迁移**。
2. **「向量记忆不复制副 api」不是代码错，是没触发点**：`seedAll()` 只在「新增副 API」
   时跑，用户手上早就有的副 API 永远等不到它 → 现在列表页有显式按钮
   （`copyFromSub`，无条件新增一份并切过去）。
