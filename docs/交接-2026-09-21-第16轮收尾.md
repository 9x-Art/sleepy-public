### 刚补的坑（本次会话最后一步）
`setAvatarBg` 只是给元素加 `has-img` 类 + 设 `backgroundImage`，
**真正让它生效的 CSS 在 `style.css` 里逐类登记**。浮岛那批头像类当初**漏登记** →
首字仍压在照片上，且没有 `background-size:cover`（图片按原尺寸撑爆小圆圈，看着就像没生效）。
已在 `style.css:5650` 改成统一登记块：

```css
/* 凡是接了 core.setAvatarBg() 的类都要在这里登记 */
.chat-item-ava.has-img,.addr-av.has-img,
.iol-ava.has-img,.iol-member-ava.has-img,.ipro-ava.has-img,.ipro-mini.has-img,
.iol-pick-ava.has-img,.pick-av.has-img{
  color:transparent;background-size:cover;background-position:center;
}
```
> **规矩**：以后任何新头像位接 `setAvatarBg`，必须回来这里登记一行，否则「头像图白接」。
