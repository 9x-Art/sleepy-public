## 0. 结论先行

**已具备条件。** 文字通道这条路口打通了：选「双人（临时测试）」+ 文字通道接口，
点生成**真的会把双人提示词发到 `/chat/completions`**（请求拦截实测，非推测）；

**没有**碰 `buildPromptForPlan`，**没有**升 CACHE、没提交、没部署。

## 1. 勘察：文字通道原本是什么样（动手前先钉死）

| 环节 | 位置 | 本轮前的事实 |
|---|---|---|
| 接口类型常量 | `imggen.js:41` `KINDS` | `general` 常规生图 / `nai` NAI / `chat` 文字通道（`label: '文字通道'`） |
| 发送分派 | `imggen.js:1114` `requestAndStore` | `(api.kind === 'nai') ? requestNai : (api.kind === 'chat') ? requestChat : requestGeneral` —— **chat 分支原本就在** |
| 文字通道拼文 | `imggen.js:1270` `requestChat` | `content = '请生成一张图片：' + built.positive + (built.negative ? '\n\n画面里不要出现这些要素：' + built.negative : '') + '\n\n只返回图片本身…'`；POST `{model, messages, stream:false}`；回图走 `extractImageFromChatText` → `b64ToBlob` |
| UI 双人守卫（上一轮） | `page-imggen.js:681`（原） | `if (twoApi.kind !== 'general')` → 拦下 + 「临时双人本轮只支持 General 接口」 |
| 折叠区常驻提示 | `page-imggen.js:524` `twoApiWarn`（本轮新） | 上一轮只有 NAI 才提示，General / chat 都不提示 |

**结论**：链路本身没缺，缺的是「接口守卫 + 说明」这一层 —— 上一轮把 chat 一起挡在门外了，
而底层 `requestAndStore` 的 chat 分支、以及 `buildTwoSubjectExperimentPrompt` 出来的那份
双人提示词，两条路都能直接用。**没有任何提示词需要为新通道另写一份。**

  走的是新双人拼接器 `buildTwoSubjectExperimentPrompt`（`imggen.js:883` 起）。
- 两条路现在**仍然是两套提示词**，各自独立；本轮没有把 legacy 那路改成新路（按基线不动）。

## 2. 取证 A：文字通道请求长什么样

来源：`scripts/browser-e2-two-visual-test.js` T8，`page.route('**/chat/completions')` 拦下并
解析 postData。断言逐条实测，非人工构造。

| 断言 | 实测 |
|---|---|
| 请求打到 `/chat/completions`，**不是** `/images/generations` | ✓（`chatCount+1` 且 `reqCount` 不变） |
| 请求体是 chat 形态且带模型名 | ✓（`model === 'two-chat-fixture'`，`messages[0].content` 存在） |
| 正文里双人结构原文 + 人物A/B 各恰好一份 | ✓ `Exactly two people are present in the image` 在 |
| 没误带 `solo` / `exactly one person` | ✓ |
| 负面以自然语言段附上，且**仍无** `elderly` / `wrinkle` / `bad hands` | ✓ `画面里不要出现这些要素：` 在，三段禁忌词都没有 |
| 同一份自定义视觉层（custom marker 恰好一份） | ✓ |
| 结果区回显标注「通道 文字通道（自然语言正文）」且不报错 | ✓，且不含「常规生图（独立 negative 字段）」 |

零付费：文字通道那一路 1 次请求被 `page.route` 拦下，夹具的 `baseUrl` 指向
`http://127.0.0.1:9/v1`（不可达地址做双保险），**没有回退真实服务**。

### 实际发给模型的正文（T8 那一次，A 组输入 + 自定义视觉词非空）

`requestChat` 拼的 `content` 原文（`imggen.js:1270-1276` 的格式，正文取自同一份
`buildTwoSubjectExperimentPrompt` 输出）：

```
请生成一张图片：masterpiece, best quality, highly detailed, Exactly two people are present in the image: Person A and Person B. Keep each person's described appearance and clothing associated with that person. Follow the scene description for their positions, expressions, gaze, actions, and any physical contact. Do not add other people or invent a relationship or physical contact that is not described., Person A（人物A）: 30 岁成年人，黑色短发，深蓝色外套，面部轮廓清晰, Person B（人物B）: 成年人，栗色肩长发，米色上衣，圆脸, Scene（画面描述）: 两人在安静的海边并肩站在一起看镜头，肩膀靠得很近但没有任何身体接触，身后是平静的海面和黄昏的光, flat graphic illustration, limited 6-color palette, thick clean outlines, soft matte texture

画面里不要出现这些要素：lowres, worst quality, low quality, jpeg artifacts, blurry

只返回图片本身（markdown 图片、图片链接或 base64 数据都可以），不要多余解释。
```

对应三段输入（本轮取证用隔离虚构夹具，非真实角色/身份）：

- 人物A：`30 岁成年人，黑色短发，深蓝色外套，面部轮廓清晰`
- 人物B：`成年人，栗色肩长发，米色上衣，圆脸`
- 想画什么（A 组场景）：`两人在安静的海边并肩站在一起看镜头，肩膀靠得很近但没有任何身体接触，身后是平静的海面和黄昏的光`
- 自定义视觉词（T8 那份非空）：`flat graphic illustration, limited 6-color palette, thick clean outlines, soft matte texture`（明显可识别的测试风格短句，用于「恰好一份」定位）

**注意**：正面 27 段词里**没有**男性 v2、没有女性 C、没有旧默认 look、没有系统手部附加词；
负面只有 `lowres, worst quality, low quality, jpeg artifacts, blurry` 这一条质量负面。

### 两条路的差异表（这是本轮唯一需要记住的差异）

| | 常规生图 General | 文字通道 chat |
|---|---|---|
| 拼出提示词的出处 | 同一个 `buildTwoSubjectExperimentPrompt` | **完全同一份**（逐字相同，T8 断言不比较是因为通道不同；正文内容由同一函数产出） |

| 失败归因 | 接口报错原文 | 模型没回图时是「文字通道没返回图片（模型可能拒绝或不会画）」 |

**模型侧是否真的支持这段自然语言生图指令 = 未知**（本轮没真发请求，也不知道你的中转站行为），

## 5. 给安乐的照做路径（含文字通道版）

**常规生图（General）**：`设置 → 生图 → 常规生图接口 → 试一张 → 主体选「双人（临时测试，不读取角色资料）」`。
（上一轮报告 §8 的六步照旧有效，本轮只补通道差异。）

**文字通道（chat）** 的差异只有三步：

1. `设置 → 生图`，配/选一个 **文字通道** 接口（`/chat/completions` 形态，填了模型名）。
2. 进该接口的「编辑」页 → **试一张** → 主体选「**双人（临时测试，不读取角色资料）**」。
   折叠区会显示一行说明：双人提示词与常规生图**完全一样**，只是整段发到
   `/chat/completions`、负面跟在后面而不是独立字段；切回常规生图才走独立 `negative_prompt`。
3. 填 人物A / 人物B（都必填）/ 想画什么 /（可选的）自定义视觉词 → 点「生成」。
   结果区回显会标「**通道 文字通道（自然语言正文）**」，可以对账。

其余与常规生图一致：视觉拼接模式仍然只锁这一次 custom（不动你存的全局值）、
镜头与手部下拉照旧收起（双人本轮镜头＝按画面描述）、**不需要建岛 / 建角色 / 建马甲**。

**三段可复制描述**（与上一轮完全一样，两条路共用）：

- **A 并肩**
  - 人物A：`30 岁成年人，黑色短发，深蓝色外套，面部轮廓清晰`
  - 人物B：`成年人，栗色肩长发，米色上衣，圆脸`
  - 想画什么：`两人在安静的海边并肩站在一起看镜头，肩膀靠得很近但没有任何身体接触，身后是平静的海面和黄昏的光`
- **B 递物**（人物A/B 同上）
  - 想画什么：`人物A 的右手握住一只透明饮料瓶的瓶身下半部，人物B 的左手接住瓶身的上半部，两人看向对方；其余手臂自然放下或被身体挡住。站在海边，黄昏，两人肩膀没有接触。`
- **C 非爱情**
  - 人物A：`30 岁成年女性，女儿，黑色短发扎成马尾，浅灰色针织开衫`
  - 人物B：`60 岁成年女性，母亲，花白短发，深咖啡色围裙，手掌粗糙有皱纹`
  - 想画什么：`母女两人在家里的餐桌边聊天，母亲（人物B）坐在左侧看向女儿（人物A），女儿（人物A）坐在右侧抬头微笑回应；桌上是两杯茶和一碟水果，没有拥抱也没有牵手。`

建议顺序：A 先看两个人在不在、位置对不对；B 看手部动作归到谁；C 看年龄与亲属关系有没有被改。
