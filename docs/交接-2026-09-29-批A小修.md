## 改了什么（按文件）

### 1. API 超时统一 60s（用户：「所有api类型的超时都改成60s」）
- `imggen.js` `newApi()`：`timeoutSec: kind === 'nai' ? 180 : 120` → **60**；
  生图调用兜底 `Math.max(60, Number(api.timeoutSec) || 60)`。
- `page-imggen.js` `collect()`：`|| 120` → `|| 60`。
- 主/子 API 默认本来就是 60（`api.js GEN_DEFAULTS.timeoutSec`、`store.js`），没动；
  TTS 无超时配置。
- **当晚补丁（用户真机「几秒就超时」→ 读路径归一）**：排查确认代码里没有秒级超时，
  是**老存档里存的小 `timeoutSec` 一直生效**。用户拍板「归一到 60s」——
  所有读路径 <60 一律按 60 跑：
  - `api.js genParams`：下限 5s → **60s**（`if (!(tout >= 60)) tout = 60`）；
  - `api.js embed`：`Math.max(60, …)`；
  - `page-settings.js` / `page-subapi.js` 测试连接：下限 5s → 60s；
  - `imggen.js` 生图调用：下限 10s → 60s（存档里更大的 120/180 照跑）；
  - 四处编辑页 numField `min` 抬到 60（hint 注明「小于 60 运行时也按 60 跑」）；
  - smoke 超时测试重写：0/1/**30** → 60、120 保留、缺省 60。
  ⚠️ 代价：用户从此**没法配小于 60s 的快速失败**（用户认可「大一些好」）。

### 2. 删大号不再连坐 NPC（用户确认的行为改动）
- `core.js doomedCharIds()`：递归家谱**跳过 `kind==='npc'`** —— NPC 永不进 doomed。
  主表删除（`cleanupChar`）与向量删除（`forgetCharSet`）共用这一个函数，
  铁律「主表 doomed = 向量命中集合」自动保持一致。
- `core.js cleanupChar(id, sbId)`：签名加了 `sbId`；挂在 doomed 名下的 NPC
  **收编归岛**（`parentType:'sandbox'`，`parentId = sbId || c.sandboxId`）——
  家谱断了但人不删，NPC 属于整座岛。
- `purgeChar` / `purgeFace` 的 `doCleanup` 都把 `sbId` 传进去了。
- `page-idcard.js`：删除确认按钮文案只数 `subChars`（不再数 NPC）；
  「删除大号会把它名下的小号和 NPC 一起删掉」脚注**整段删除**（用户：「这句解释有点多余」）。
- smoke `P4-M11` 重写为新语义：删大号 doomed={大号,皮套}，名下 NPC 全活且归岛；
  三处「当前状态」正向断言翻成反向断言（见下）。

### 3. 认知第三档去「平行宇宙」（只改文案，不动数据语义）
