# 一. 聊天

> 🙌 聊天功能很多，这篇挑复杂的说~ 常规收发一眼就会，就不啰嗦啦！

## 1. 先知道的几件小事

- A. 输入框空着直接点发送 = 让 TA 先开口，冷启动救星~
- B. TA 的长回复会自动拆成好几条气泡、按打字节奏一条条蹦出来，不是卡了喔
- C. Enter 发送、Shift+Enter 换行
- D. 消息列表里**长按会话**：置顶 / 改备注名 / 删除对话

## 2. 加号面板（输入框旁的 +）

- **停止** —— 掐断正在生成的回复；只在等回复时出现，平时不占位
- **重说** —— 最后一条回复重新生成；不满意就点它，不扣额外的额度说明见对话设置
- **发照片 / 视频 / 文件** —— 发本地文件给 TA，走系统选文件框
- **转账** —— 转账给 TA；单笔上限 99999，备注点卡片可看全文；钱包 App 有流水
- **拍一拍** —— 拍 TA 一下，对话里出灰字提示
- **生图** —— 生成一张图；要先去 设置→生图 配接口！还需要主 API 来想画面
- **查岗** —— 让 TA 汇报此刻在干嘛；同样要生图接口 + 主 API
- **文字麻将** —— 和 TA 开桌 1v1，牌局直接在对话里打
- **反查手机** —— 让 TA 偷看你的手机；要在对话设置里开「反查手机」开关，TA 同不同意看他自己的倾向~群岛里 char 反查能看到你和别的 char 的对话喔（当海王需要管理能力！）
- **日记** —— 打开日记，直达
- **翻译** —— 开关：显隐外语译文；TA 的常驻地点只说中文时这项是灰的，语言由地点推，不是手动切换的喔

⚠️ 表情包入口在输入框里的笑脸钮；面板里没有红包和语音~

## 3. 气泡怎么摸

**A. 左滑 = 引用**
任意气泡往左一滑，输入框上方出现引用条（「我：…」/「TA 名：…」），接着打字发送就行。引用条上的 × 是取消。发出去后引用以小字挂在你的气泡里，TA 也会引用你的话~

**B. 长按约半秒 = 消息菜单**

- 顶部一排 emoji：快速贴个回应
- 引用 / 复制 / 转发 / 收藏 / 编辑：常规操作
- **留在灯上**：把这句话挂到桌面挂件「灯」上，回桌面就能看见
- **TA 的自察**（条件项）：看 TA 对这段对话的内心自察
- **多选**：进去后**点击气泡**就是勾选，可逐条转发 / 合并转发（合并后是一张「聊天记录」卡）/ 批量删除
- **撤回**：只有自己发的纯文字能撤

**C. 点自己头像 = 情绪印章**
一个心情章直接盖进对话，**跨天自动失效**~ 纯章的消息是印章气泡。

**D. 点 TA 头像 = 心声**
TA 没说出口的心里话！有新心声时头像上有呼吸光点（雾蓝色的小点点）。

**E. 关于撤回的小心机**
TA 撤回的消息你看不看得见原文是有概率的，默认 40%，滑条在对话设置里。TA 的撤回显示成灰字条，点开能看内容和原因。

## 4. 搜索聊天记录

顶栏放大镜进入：

- A. 空态是分类网格：图片与视频 / 文件 / 链接 / 语音 / 转账 / 表情包 / 小游戏 / 带引用，每类带条数
- B. 打字即全文搜（上限 50 条）
- C. 点任意结果会跳过去并**闪烁 1.6 秒**，顶部还有本对话的概览（总条数 / 时间跨度 / 最近一条）

## 5. 语音（TTS）

- A. 语音条是 **TA 主动发的**（角色配了语音就可能在合适的时机发），不是你录音喔
- B. 点语音条播放/暂停，旁边「文」小钮切换文字稿显隐
- C. 前置两道：**设置→语音 TTS 总开关** + **该角色填了音色 ID**，缺了会有 toast 提示去哪配
- D. 语音不可转发~

## 6. 线下模式（叙事流）

聊天顶栏的门图标进入，弹「**新的 / 继续上次**」。

- A. 区别：线上是一来一回的气泡；线下是**叙事流**——场景框 + 你的行动 + TA 的台词 + 建议选项，可以另设壁纸、文风、镜头
- B. **暂停或结束都会交接回线上**：线下发生的事会转录（最多 3 条）进对话，TA 下一轮线上回复记得刚才发生了什么，不用担心断层~
- C. 前置：对话必须已绑定角色，没绑会 toast 提醒

## 7. 群聊

- A. 消息页顶栏「新建 → 发起群聊」，三步：发起账号 → 选成员 → 群资料
- B. **长按成员头像**快速 @；左滑引用、长按菜单在群里一样能用
- C. 群详情可改群名 / 头像 / 成员 / 邀请 / 退出；**没有踢人、群聊不支持转发**喔
- D. 群记忆会自动总结（≥30 条或 ≥6000 字或跨 3 个活跃日时触发），不用手动操心

## 8. 对话设置（顶栏齿轮）里值得点开的

- A. **主动消息**：TA 可以自己先开口！可调节奏，还有「现在评估一次」手动触发
- B. **聊天外观**：classic / 企微 / 捡手机三套皮肤
- C. **撤回被看到概率**滑条：默认 40%
- D. **朋友权限 / MCP 工具开关 / 查手机档位 / 记忆整理模型 / 角色语音**：都是按对话独立配的
- E. **导出对话**：纯文本导出
- F. 清聊天记录没有独立入口，全局备份走 **设置→数据与备份**（导出 .json，⚠️ 图片不包含在内！）

## 9. TA 侧的「演出」速查

这些不是你操作的，是 TA 自己的行为，看到别慌：

- **TA 发的图**：TA 自己生的，点开可以**重画**
- **灰字「撤回了一条消息」**：TA 撤回了，点开看内容+原因
- **小游戏卡片**：可玩！支持全屏，结算结果会回喂给对话
- **「慢递」信**：TA 写的延迟信，到时间才送到
- **TA 换了头像**：TA 自己换的（也可能是在反查手机看到你和别人的情侣头像后…出点小事 www）
- **收藏提议卡**：TA 提议把聊到的时刻记进收藏馆

## 10. 前置条件速查

- TA 正常回话 —— 主 API 配好
- 生图 / 查岗 / TA 发图 / 重画 —— 设置→生图 接口 + 主 API
- 语音条 / 朗读 —— TTS 总开关 + 角色音色 ID
- 翻译 —— TA 的常驻地点会外语
- 反查手机 —— 对话设置里开「反查手机」
- 线下模式 —— 对话已绑定角色

# 二. 世界书

> 🙌 世界书就是给 TA 的「设定资料库」——他的世界观、经历、冷知识，一条条写在这里，聊到了才会带进上下文，不吃没必要的 token~ 纯本地功能，**不需要配任何 api**！

## 1. 先知道的几件小事

- A. 桌面和聊天底栏都有入口
- B. 结构是两级的：**书 → 条目**。先建一本书记一个主题（比如「青岚镇设定」），里面再一条条加内容
- C. 条目正文**原样存、原样注入**，不解析格式，带 markdown 还是带符号都随你

## 2. 书的两种范围

**A. 全局书**
所有对话都可能用到，适合世界观、地名、公共设定这类「大家都该知道」的内容。

**B. 个人书（挂角色）**
只挂在某个角色身上，**聊到 TA 才会召回**，适合「只有 TA 知道的事」。

步骤：新建书 → 打开「挂在特定角色」开关 → 点「挂到谁身上」选人 → 保存。

⚠️ 群聊里分得清楚：全局书进**共享上下文**（大家都看得到）；个人书只进挂的那个 TA 自己的块——挂在群外角色身上的个人书**整本不注入**，不会广播出去。

## 3. 条目：常驻 vs 关键词触发

每条 二选一：

**A. 常驻（开关打开）**
不靠关键词，**一直生效**。适合核心设定，但别开太多——占固定上下文。

**B. 关键词触发（默认）**
对话里提到**其中任意一个**关键词，这条才被带进上下文。

- 多个关键词用**逗号或顿号**隔开：`北门，渡口，码头`
- 匹配是**子串命中**：关键词写「猫」，说到「猫咖」也算命中，所以关键词不用写全称
- ⚠️ 没设关键词、又没开常驻的条目 = **永远不会自动触发**（条目列表里会标出来提醒你）

**C. 条目开关**
每条右侧有开关，随手停用某条而不用删——停用的条目不注入。

## 4. 生效规则（免得疑惑）

- A. 单轮**最多注入 10 条**（常驻优先占位，然后是命中的关键词条目），写太多也不是越多越好
- B. 关键词是在**最近一段对话**里找的，太早之前提过的词不算命中——需要长期稳定的设定请开常驻
- C. 书也有总开关，整本停用就全都不生效

## 5. 导入 / 导出

右上角就是导入导出，收**纯文本 .txt**，格式长这样（导入失败时也会把这个模板递到你手上，照抄就能用）：

```
===== 世界书：示例书名 =====
范围：全局

===== 条目：他养的猫 | 关键词：猫，煤球 =====
正文写在这里。对话里出现「猫」或「煤球」时，这段才会注入给模型。

===== 条目：他的口头禅 | 常驻 =====
常驻条目不靠触发词，一直生效。
```

- A. 个人书会多两行元信息：`范围：个人` + `挂角色：名字`，导入时按名字对号入座
- B. **同名书/条目会覆盖**（幂等导入），重复导入不会越堆越多
- C. 只有条目、没有书头的老文件也能导：整包进一本新的全局书，名字取文件名
- D. 条目编辑页还有「导出这条」，单条分享用

⚠️ 两类文件收不了：**Word 文档**（docx 是压缩包，按文本读全是乱码——复制出来存 .txt 再导）；**JSON 世界书**（多半是酒馆导出的，这里不收这个格式，照上面的纯文本模板抄一遍就能用）。

## 6. 暗铺书（🔒）

从「设定仓库」下载的世界书可能是**暗铺书**：

- A. 条目目录能看，但**内容是作者锁起来的**——能用、看不到原文，也不能增删改和导出
- B. 条目开关随便拨，不想让某条生效就关掉它
- C. 作者锁起来的内容不会从这里二次泄露，所以暗铺书没有导出按钮

## 7. 写好关键词的小建议

- A. 关键词写**短、常用**的词，别写长句——子串匹配，越短越容易命中
- B. 同一个条目多给几个变体（「煤球」「猫」「那只猫」），命中机会更大
- C. 万金油词（「他」「今天」）别当关键词，会把条目带的次数撑爆

# 三. Ta

> 🙌 Ta 是 TA 的「生活窗口」——只读展示他此刻的状态、在做的事、留意的东西、身边有谁。**打开这一页不会让他多做任何事**：不调模型、不写数据，纯看~

## 1. 先知道的几件小事

- A. 桌面第 3 屏进入。孤岛直接进；群岛会先问「想看谁的生活？」，点选再看
- B. 没落岛 / 没选角色时是空态：「先在桌面选一间房」
- C. 首页四个区：
  - **01 此刻/最近状态** —— 他现在的状态，带更新时间
  - **02 最近在做** —— 进行中的事项（已完成的收在「幕后」）
  - **03 一直留意** —— 他在留意的東西（过期了也只是陈列，不替你下结论）
  - **04 身边的人** —— 有依据的人物 + 「关系网 →」入口
- D. 没有真实数据时就空着，**ta 不编生活**——这页没有一句是装出来的

## 2. 三张表（事项 / 承诺 / 关注）

顶栏「**记一笔**」手动录入，类型三选一：

- **A. 事项** —— 他在做什么、卡在哪、什么时候再看。五个状态：进行中 / 受阻 / 待核实 / 暂停 / 已完成
- **B. 承诺** —— 他说过的话，尽量照原样记。⚠️ **承诺永远不会自动判兑现**：事项完成、日历走完都不会自动兑现它，只能你亲手确认——这是刻意的
- **C. 关注** —— 他在留意什么。这个**没有「完成」的概念**
- D. 状态快改在详情页；删除是两步确认（点一下变「再点一次确认删除」）

## 3. 幕后（顶栏进去）

管理三张表全量 + 几个重要玩法：

- **A. 生活提案** —— 模型生成的东西（事项/关注/承诺复核/NPC 事件/影响…）**先落「待审核提案」，你点「接受」才生效**，没接受的不进聊天、不进召回。可以全部舍弃~
- **B. 三个按钮**：「复核现有事实」（不需要开关）/「生成一轮生活提案」（要开「自主生活更新」）/「提名 NPC 候选」（至多 3 个）
- **C. NPC 候选** —— 确认入库要勾三个授权：确认存在 / 故事内 user 认识他 / 允许低风险自主发展。缺「确认存在」不放行
- **D. 影响** —— 五态：生效中 / 已淡了 / 已过期 / 已解决 / 依据已失效。⚠️ **「已淡了」「已过期」都不等于解决**，只有手点「标记已解决」才算
- **E. 关系人** —— 你给 TA 身边补的「活人」：名字/关系/亲疏/你确立的事实。⚠️ **名字只能在新建时定**（改名=换人）；软上限 6 人

## 4. 关系网

- A. 只画**有依据的连线**——没有记录就不画，不为了好看虚构一条
- B. 图上最多画 8 位，超出的在列表视图里看全
- C. 点节点/连线出详情：关系出处、最近的近况（来自 TA 本人发的朋友圈）

## 5. 哪里会调模型

- 打开任何页面、记一笔、改状态、审核提案 —— 纯本地
- 详情页「让 ta 复核或推进」 —— 要（主 API）
- 幕后三个生成按钮 —— 要

> 模型有硬性禁令：不编造死亡、结婚、分手这类重大变化，没证据不许标「已完成」，也不能替你做决定~

## 6. 容易疑惑的点

- A. 首页 02 区看不到已完成事项 → 去「幕后」看
- B. 「玩家查看 ≠ 角色知情」——你在这页看到的一切，TA 不知道你看了

# 四. 留痕

> 🙌 留痕是 TA 的记忆库——你们聊过的事会被收进这里，聊天时按需注入给模型。浏览、搜索、手动加记忆全部**纯本地**~

## 1. 先知道的几件小事

- A. 桌面第 2 屏进入。结构三层：**岛 → 角色 → 条目**，首页显示当前打开那座岛的数据
- B. 角色行能看到：待确认小红点、记忆状态（完整记忆/简化记录/未开启）、记忆开关、最新记忆摘要
- C. 顶栏「搜索记忆」全文搜（上限 30 条）；「新增记忆」先输角色名再进内页添加

## 2. 记忆条目

- **A. 类型 11 种**：喜欢 / 不喜欢 / 边界 / 事实 / 共同经历 / 约定 / 关系 / 纠正 / 习惯 / 推测 / 自定义
- **B. 状态 5 种**：当前有效 / 待确认 / 已标记错误 / 已被替代 / 已归档
- **C. ⚠️「推测」类型手动加不了**——推测只能由系统整理产生，这是防污染设计

## 3. 待确认（pending）机制

系统自动整理出来的记忆**不一定直接生效**：

- 你**亲口说过**、且明确发生的 → 直接生效
- 他的推测、观察 → 先列为「待确认」，**确认之前不注入对话**

确认入口：详情页单条「确认」；或内页待确认筛选下「全部确认（N 条都有效）」批量按钮（拿不准的先去详情页看原文qwq）

## 4. 自动整理什么时候跑

自上次整理后**累计消息 ≥30 条** 或 **待整理原文 ≥6000 字**，任一满足就在后台跑一次，不阻塞聊天。一次最多整理最近 120 条。整理完会弹可点击的 toast：「悄悄整理了 N 条新记忆，点这里去留痕看看~」

> 记忆整理用的模型可以在对话设置里单独指定；没指定跟随主 API（会烧主 API 的钱，配个便宜小模型更划算）

## 5. 删除规则（重要！）

- **只有你自己手动添加的能物理删除**
- 系统整理的只能「**标记错误**」——不再召回，但原始数据保留
- 记忆的来源标识不可篡改；被替代的条目有版本链可互相跳转

## 6. 注入规则（免得疑惑）

- A. 单次注入**总量 12 条**（约定先占 4 席、共同经历保底一半、边界/纠正类有上限不许吃满整张表）
- B. 「**锚定**」的条目不吃配额、始终优先——最重要的记忆给它上锚
- C. 注入末尾会带最新一条推测，明标「[我的推测]」——是推测不是事实

## 7. 记忆开关（按角色）

- A. 开关在角色行上直接拨。记忆归「大脑」不归脸：**同一角色的皮套共用一份记忆**
- B. **主角默认开，NPC 默认关**。关掉后数据全保留，只是不再注入对话

## 8. 向量记忆（按话题找回聊过的东西）

需要**单独配一个 embedding（向量）接口**。⚠️ **这个不配就整个没开，不会自动拿主 API 顶上**，也不会偷偷发注定失败的请求。配了之后，聊到相关话题时旧记忆会被按语义找回来，不只靠关键词~

## 9. 内页筛选

六格分类（我是什么样的人 / 我们一起走过的 / 你亲口告诉我的 / 最近的你 / 我现在这样理解你 / 还没说完的事）+ 状态/来源/关键词筛选，四重条件叠加。详情页「查看原文」能跳回聊天里那条气泡~

# 五. 查手机

> 🙌 桌面第 2 屏。捡手机文学成真了——趁他不在，翻翻他的手机。怎么进去本身就是内容的一部分：**试过就会留下痕迹**喔~

## 1. 怎么进去

- A. 孤岛直进；群岛先问「谁把手机落在这里了？」（只列正式角色——**皮套不算人，手机属于人**）
- B. 第一次偷看**屏幕一定还亮着**，直接看；之后每次 50% 概率他刚好走开没锁
- C. 锁屏后四条路：
  - **「使用你记得的密码」**——密码默认由**你们岛落成的日子**（4 位）派生，这是你合理知道的关系事实；猜中一次以后就记住了
  - **「只看一眼，然后放回去」**——停在锁屏看通知，不试密码、不留会话
  - **「收手」**——试过密码的会留下失败记录，没试过的干净收手
  - **「趁他不注意，硬翻」**——有被发现的风险，概率锁屏上明写
- D. ⚠️ **他没设密码 ≠ 可以随便看**：照样留痕、照样消耗行动、照样可能被抓
- E. 连错 5 次密码手机会暂时锁定；硬翻被抓概率 = 基础档（20%/30%/40% 三档，锁屏右上角小齿轮可调）+ 情境加成（刚放下手机/有锁/有失败痕迹都会加），**封顶 85%**——永远留一线可能

## 2. 手机里有什么（八个面）

- **消息** —— 幕后交流（他和别人的对话）/ 群聊（只读）/ 你们私聊的镜像 / 未发送的草稿
- **淘宝** —— 订单 / 收藏 / 购物车，订单带物流时间线和用途线索
- **健康打卡** —— 饮食 / 运动 / 随手记，只有记录没有评分
- **备忘录** —— 分组的随手记
- **浏览器** —— 搜索记录 + 收藏（搜索说明他想过，收藏才是他准备留下）
- **音乐** —— 最近在听 / 红心，「循环 ×N」暴露心情；详情有心声
- **短信** —— 系统通知（验证码/快递/银行，程序生成的）+ 真人短信（带未读点和心声）
- **书架** —— 在读进度 + 划线批注

壁纸和强调色按角色固定派生，每次进来都一样~

## 3. 内容从哪来（刷新机制）

- A. **打开手机本身 0 次模型调用**，全是已有数据
- B. 桌面右上角「**刷新**」= 一次整体结算，每次 **3~5 条**新内容；单个 App 页里也能单独刷新
- C. 第一次可以点「**初始底片**」铺底：轻量 / 丰富 / 只用真实互动（第三档完全不调模型）三档选
- D. **自主生活档位**（关/低/中/高）在角色设置里调——他不在你眼前时也会自己过日子留下痕迹；聊天后也可能悄悄结算（有 toast 提示）
- E. 联系人池空着的时候，允许模型按人设编 1~2 个**背景联系人**（朋友/同事/家人），登记之后就长期有效啦

## 4. 编辑与红线

- A. **短信 / 音乐 / 书**的详情可以编辑（改错字、补心声）；⚠️ **书名不能改**（批注按书名挂着，改了会变孤儿）；备忘录/浏览器/淘宝/健康没有编辑入口
- B. 编辑是改**已有**记录，不是替他编新的~
- C. 工坊装给他的自定义 App 在这里**纯只读**，不接刷新

## 5. 被察觉（紧张的部分！）

- A. 行动会消耗「预算」，超支后环境提示一步步逼近：「门外很安静。」→「走廊里好像有动静。」→「有脚步声，正在靠近。」→「门把手轻轻响了一下。」
- B. 当场被抓是概率掷骰，**没有「第 N 次必抓」**；授权会话（他向你开放过）恒为 0
- C. 被抓时实时生成他的反应（要主 API）；没配 API 就如实告诉你「等你回到聊天里就知道了」——不编假台词
- D. 翻过的痕迹可能让他事后起疑；他也会把某些 App **藏起来**（图标带锁），桌面底部会留下他给的说法

# 六. 工坊

> 🙌 工坊是你做小东西的地方——做好**装进 TA 的手机里**，装给几个人就各自独立记各自的。全程 **0 次模型调用**~

## 1. 先知道的几件小事

- A. 桌面第 2 屏进入
- B. 三层结构：**模板（你做的）→ 安装（装给谁）→ 记录（TA 自己记的）**
- C. ⚠️ **内容是 TA 写的，不是你写的**——工坊里没有「替他加记录」的入口；你能做的是做模板、安装、卸载

## 2. 六种内置模板

- **✎ 日记型** —— 一天一页：日期 / 标题 / 正文
- **◉ 打卡型** —— 每天一笔：日期 / 事项 / 完成了没
- **❋ 收藏型** —— 名字 / 为什么喜欢
- **▤ 进度型** —— 在做什么 / 到哪儿了 / 备注
- **❏ 档案型** —— 一个人或一件事：名字 / 详情
- **⋯ 时间线型** —— 什么时候 / 发生了什么

内置模板跨岛可用、**删不掉也改不了**~

## 3. 自建模板

选类型 + 起名（≤12 字）+ 一句话描述（≤40 字）+ 强调色。⚠️ **模板名就是钥匙**：模型往这个 App 里写内容时认的是模板名，名字对不上就静默丢弃，所以起名别乱改qwq

删除自建模板会**连带撤掉所有装出去的实例**（记录归档不删，但手机上看不到了），弹窗会提醒你~

## 4. 装给谁

- A. 「装给谁」抽屉勾选角色（默认全选、可多选），**每勾一人 = 一份独立实例，记录互不同步**
- B. 同一部手机同一模板装不了第二份
- C. 装完去 TA 的手机桌面就能看到新图标（官方 App 排在后面）
- D. 卸载：记录归档保留，只是手机上不再出现——数据不会悄悄消失~

## 5. 容易疑惑的点

- A. **贴纸工坊不在工坊里**（在收藏馆）；**自制桌面组件也不在**（在组件商城）。工坊只做上面这六类
- B. 在查手机里看这些自定义 App 是纯只读的，没有刷新按钮
- C. TA 记的内容（或结算生成的）都标着来路，展示即生效、不会被后续生成覆盖

# 七. 外观

> 🙌 外观分两层：**全局外观**（整部手机长什么样）和**角色聊天外观**（聊天页穿什么皮肤）。全部纯本地，不需要任何 API~

## 1. 全局外观（桌面第 3 屏「外观」）

- **A. 4 套配色**：奶蓝（默认）/ 夜灯（唯一深色，夜间模式就是它）/ 蜜桃 / 薄荷
- **B. 5 款壁纸 + 自定义图**：跟随主题 / 奶油 / 蜜桃 / 海盐 / 暮色（唯一深款）；自定义图自动压一层白纱保证字能读
- **C. 4 种图标风格**：玻璃（默认）/ 线框 / 纸片 / 夜色
- **D. 其他**：较大桌面文字、动效开关、正文字号三档、正文字颜色（20 预设色 + 自定义）、自定义字体（.woff2/.ttf/.otf 直链）

⚠️ **草稿-保存模型**：页面里怎么改都只动顶部预览，**要点底部「保存外观」才真正生效**！（「单独修改 App」和美化预设例外，即时生效）

## 2. 应用范围：全局 vs 指定岛

- A. 可按岛覆盖的：壁纸 / 图标风格 / 配色 / 较大桌面文字
- B. 永远全局的：字号 / 动效 / 字体 / 正文字色
- C. **岛覆盖 > 全局**，没有第二道开关：岛没设置的就跟随全局；「恢复这座岛并跟随全局」可以删掉覆盖

## 3. 单独修改 App

从外观页进去，能改每个桌面 App 的**显示名称（≤8 字）**和**自定义图标**，即时生效。单 App 修改优先于整套图标风格~

## 4. 角色聊天外观（对话设置 → 外观）

- **A. 三套预设**：默认 / 企微 / 捡手机。皮肤模式下**颜色、底纹、装饰不能调**（要点「先切回默认预设」），壁纸 / 圆角 / 字号照常可用
- **B. 默认预设下能自定义**：壁纸（色板/夜色渐变/图片，带模糊和遮罩滑杆）、气泡圆角与尾巴、底纹、装饰、6 块色板（藕粉/雾青/旧玫瑰/雨蓝/茶金/墨灰）、氛围浓度、字号与间距
- **C. CSS 高级自定义**：一段 CSS 注入**整个聊天页**，切预设不会洗掉它

> ⚠️ 私聊 CSS 和群聊美化 CSS **共用一个槽**：进群聊自动摘私聊 CSS、回私聊摘群 CSS，同一时刻只生效一份~

- **D. 应用范围**：角色专属 > 全局默认 > 出厂；设为全局默认会收掉该角色的专属配置
- **E. 「允许 TA 自己换头像」**（默认关）：开了 TA 才能从头像库挑图换头像，库在「编辑角色」里存

## 5. 美化预设

从御膳房领的「摆盘」导入时选「先存进美化预设」就会到这里，可以随时应用（即时生效）或删掉~

# 八. 组件商城

> 🙌 桌面上摆什么，来商城挑~ 删掉的组件也都在「你删过的」里留着，能**放回原来的位置**。纯本地功能~

## 1. 货架上有什么

**A. 上架的 6 件**：

- **角色卡**（1×1）—— 当前角色的头像+名字
- **倒数日方**（2×1）—— 大数字倒数，**点组件设日子**
- **天气小方**（1×1）—— 天气感知的温度小砖（要先去设置配天气）
- **日期时钟方**（1×1）—— 日期+时间+星期
- **拍立得墙**（2×2）—— 手选相册照片，白边斜贴
- **慢递信箱**（2×2）—— TA 写的慢递信，**到点才能拆**

**B. 默认户型自带的**：灯、时钟、双时钟、电量、播放器、日历、待办、照片墙、心情印章、头衔日期、帷境通栏、模式章、留白——误删了都能从这里装回来

## 2. 装 / 拆 / 回收站

- A. 「**加到桌面**」→ 自动找第一个放得下的空位；放不下会明说「先去编辑态腾一腾」，不硬塞~ 同型号可以「**再摆一件**」（想要两块时钟完全可以）
- B. **长按桌面进编辑态**：拖动换位（能拖到别的屏）、点小叉叉拿掉
- C. 「**你删过的**」最多列 12 条，按岛隔离；装回时**优先放回当初拿掉的位置**，位置被占才找空位

## 3. 自制组件

**A. 模板 = HTML/CSS + {{变量}}**，宽 1~4 × 高 1~6 自由定形状，左编辑右实时预览

**B. 安全边界**：**只做变量替换、不执行脚本**——script、事件属性、javascript: 一律剥掉；CSS 自动钉在组件自己的作用域里，漏不出去污染别处~

**C. 可用变量**（取不到就留白不报错）：

```
{{time}} {{date}} {{weekday}} —— 时间日期星期
{{weather}} {{weatherCity}} —— 天气快照（要配天气感知）
{{photo}} —— 随机相册照片
{{lampNote}} {{charName}} —— 灯上留言 / 当前角色名
{{todoCount}} —— 未完成待办数
{{countdown:2027-01-01}} —— 倒数（带日期参数）
```

**D. ⚠️ 自制模板跟着岛走**：换一座岛看不到；删掉模板后已摆出去的格子会显示「模板不见了」

## 4. 容易疑惑的点

- A. 大组件（2×2）在默认户型里经常找不到空位，装不上不是 bug，腾一腾就好
- B. **天气小方要先配置**：设置 → 天气感知，开开关 + 填城市 + 填 OpenWeatherMap key（免费），缺了点它会提示你去哪配
- C. 灯组件卡上有专属「**设置**」：换灯光四档（暖灯/月光/自然光/烛光）、设灯牌字体、管理灯上的留言

# 九. 群声

> 🙌 群声是桌面第 3 屏的**公共论坛「众声喧哗」**——报纸风格的小社区，TA 们和你都在里面发帖、回帖、投票~ ⚠️ 它不是群聊喔！群聊在「一. 聊天」里讲过了

## 1. 页面结构

底栏五钮：**首页 / 板块 / 发布（中央圆钮）/ 消息 / 我的**

- A. 首页三 tab：杂响（全部）/ 关注 / 最新；下方「第 N 期」信息流无限滚动
- B. 八大板块（每座岛自动配齐）：日常生活 / 情感求助 / 树洞（匿名，首页「泡泡糖」直达）/ 同人创作 / 摄影与旅行 / 美食与探店 / 游戏区 / 本地生活
- C. 「我的」里管身份：马甲=独立论坛账号，**大小号互不公开关联**；TA 们以大号身份出没（皮套不直连）

## 2. 发帖

- A. 类型：普通帖 / 长文 / 求助 / 投票 / 帷境作品
- B. 附件：图片最多 **3 张**、投票（2~6 个选项，**发出后不能改**）、帷境作品（只带公开投影，创作手记绝不进论坛）、📍地点（纯文字标签，不做真定位）
- C. 单帖匿名：同帖内同一个匿名者是同一个别名，**跨帖认不出来**，也没有作者主页
- D. 「仅关注者」可见的帖子，非关注者点开会看到一句「这篇只给关注的人看」

## 3. 互动

- A. 点赞叫「**同感**」；投票**投一票才揭晓结果**（防从众~），可改投、点自己那项=撤票
- B. 转发四路：转到我的主页 / 分享到朋友圈 / 发到本岛私聊 / 发到本岛群聊，都可附言
- C. ⚠️ **阅读数和「第 N 期」是装饰性数字**，不是真实统计；也没有举报钮——不做假的按钮~

## 4. 让社区动起来（这些会调模型）

- 首页「催更」 —— 开张生成种子帖 / 已开张补 2~4 帖新帖
- 详情页「催一下」 —— 请 TA 或居民来这帖回帖
- 板块页「催一下」 —— 只给这个板块生成 1~3 帖
- 首页「@ ta 发帖」 —— 让 TA 自己刷论坛、自己决定发不发——**允许沉默**
- 同人区「请人代笔写一篇」 —— 调模型写一整篇，不满意可以不发

冷却：催更/催一下 60 秒；@ ta 发帖每个 TA 10 分钟一次。没配 API 时按钮会失败并提示，社区保持空态**不伪造内容**~

## 5. 和聊天的联动

把帖子分享进聊天，TA 点开会回应你（带人设的），并落一条记忆「在群声分享了帖子《…》」——⚠️ **帖子情节不会变成 TA 的亲历记忆**，看过 ≠ 经历过~

## 6. 容易疑惑的点

- A. **每个岛一个独立社区**，切岛互不相通
- B. 消息中心按**当前身份**收信：切小号看不到大号的通知，互不暴露
- C. 作者可以删帖（分享卡显示「已由作者删除」）；追更时最近的读者留言会给「作者」过目，听不听由作者决定~

# 十. 御膳房

> 🙌 御膳房是**设定打包分享站**——把岛里的角色、世界书、预设、美化、整岛打包上架，别人凭门牌或公共铺面领取。**明厨**全公开，**暗铺**藏内容~ 它要走网络（下载/上传），但全程不调模型、不花 API 钱

## 1. 页面结构

底栏五钮：**首页 / 板块 / 开炉（中央圆钮）/ 消息 / 我的**。六大板块：

- **名帖** —— 角色卡
- **食单** —— 世界书
- **火候** —— 预设
- **满汉全席** —— 整岛包
- **入席** —— 以身入局（世界档案）
- **摆盘** —— 美化（配色+壁纸/图标）

⚠️ 只收 sleepy 自有格式，**不收酒馆（SillyTavern）卡**；单件上限 5MB

## 2. 明厨 / 暗铺

- **明厨**：内容全公开，能看全文、看样式
- **「需对暗号」**：作者设了暗号，**领取时对上才带得走**
- **「含暗铺件」**：内容锁着但**能用**——世界书目录可见、注入照常，只是看不到原文；美化不影响使用但看不到样式代码

**门牌**：「我的 → 暗铺门牌」输口令或粘链接进圈；进过的货架可一键复制分享链接（`…/?g=口令`），别人点开即进~

## 3. 开炉（发布）六步

这件是什么 → 怎么称呼它（可带封面图 URL）→ 给谁看（明厨铺 / 暗铺+暗号，每件可单独拨明暗）→ 包里的件 → 作者的话 → 预览发布。发布前要**先进一座岛**才有东西可打包~

## 4. 领取后东西去哪了（按类型）

- **角色卡** —— 当前所在岛
- **世界书** —— 世界书库（原挂靠角色不在→自动转全局书）
- **美化** —— 三选：存进美化预设 / 应用为全局 / 应用到当前岛
- **预设** —— 二选：叠加到现有 / **整套装上（会清掉你原来的，想清楚！）**
- **以身入局档案** —— 当前岛的档案架，**从零开局**（打包者的进度不带过来）
- **整岛包** —— 生成一座**新岛**；角色和档案全带，**聊天记录、朋友圈、照片、马甲、API 配置一律不进包**

## 5. 我的 / 账号

- A. **没有账号系统**：发布时生成作者令牌存本机——⚠️ **令牌丢了就无法再管理该件，不找回**
- B. 资料卡（昵称/头像/简介）只用于御膳房署名；评论（席间）匿名，只署铺子昵称
- C. 头衔目前实装 2 枚（开炉掌柜 / 尝过一口），其余是占位，等后续版本点亮
- D. 「我的」里可以下架自己的件、重新导入领过的（近 20 条）

## 6. 容易疑惑的点

- A. 领取条件（交尝后感 / 点赞 / 席间说一句）目前是**软门**，主要靠展示提示
- B. 服务没开通/连不上时显示「仓库服务还没开通——等下一版更新就好」，不是你的问题~
- C. 门牌码填了但没勾「同步公共铺面」→ 件只进私人小圈子货架，公共铺面看不到

# 十一. 以身入局

> 🙌 进入一本**已经存在的故事**执行委托：TA 是局里员工，你是老板（看戏或亲自下场）。桌面第 3 屏进入，进世界后每轮走一次模型；结算、判定这些账目全部本机算，不被模型糊弄~

## 1. 先知道的几件小事

- A. **先进入一座岛**，局里才有你的档案架；所有数据按岛隔离
- B. ⚠️ 局里的剧情**不写进角色记忆、不进聊天上下文**——出了局，TA 的生活照旧
- C. 每座岛自动配两个盒：「局内演练」（内置小世界，随便玩）+「待上架的世界」

## 2. 搞一本自己的世界（TXT 导入）

选 .txt → 认不出乱码就切编码（UTF-8 / GB18030）→ 自动切章（「第X章/回/卷」，切不出按段落兜底）→ 点圆点选**起始章** → 填世界名、委托（**必填**）、TA 扮演角色 → 「交给档案员预读」。

预读是一次轻量 AI 调用：产出简介、最多 6 个 NPC、地点、剧情节点、委托建议。**预读失败不拦上架**~ 原始文本会留档，删了盒还能重新上架

## 3. 领局牌（开局三步）

**A. 局内身份三选一**：

- **老板·纯看** —— 看 TA 自己走，可以开自动档「让 TA 自己走一段」（⚠️ 自动档离开页面就停）
- **老板·亲自参与** —— 你也在场，写行动落进世界
- **员工** —— 你是局里打工人（局印用不了，局印认老板www）

⚠️ **每个世界身份定一次就锁死**（演练盒例外，每次可重开）

**B. 穿书占位** —— 借宿的旅人 / 新来的帮工 / 外来的调查员（演练世界内置）

**C. 委托与场景** —— 贴场景图、看委托卡；TXT 世界还有档案员建议委托，不满意可以换个委托者重提

## 4. 游玩页

- A. 顶部常驻：委托卡 + **异常度**（≥40 标红，≥60 世界开始正式查你）+ **进度** + 身份
- B. 每轮产出一条行动日志：你的输入 / 局印批注 / 正文 / 判定
- C. **局印** = 传话工具：写好「盖下传话」，**并进下一轮**生效，不单独调用、可撕掉
- D. 局中口袋（右上滑栏）：按身份换装——纯看时是 TA 的背包（只读，**老板不能替 TA 用东西**）；亲临时是自己的背包 + 手机
- E. 设置里可选**模型连接**（跟随全局或指定主/副 API；⚠️ 指定后失败**不回落**）+ 每轮描写字数三档

## 5. 判定与结算

- A. 模型每轮末尾交判定块：异常度+N、进度%。**异常度只升不降**；缺判定块=白走一轮但正文照收
- B. TXT 世界：对原作的改动记进**改动账本**；章节**只许向后推进**；⚠️ **世界里的角色不知道原剧情、不知道委托、更不知道局的存在**
- C. **结算封档**：分数由本机按记录算（完成度=进度、规则遵守=100−异常度、能量点=30×完成度+实物×2），**模型只写叙述不许现编数**。可以请一段结算叙述，也可以直接封档

## 6. 容易疑惑的点

- A. 「能量」目前恒显「—」——结算批次开张前是占位，不是坏了qwq
- B. 「待上架」的盒进不去是设计（等世界包定稿）；异常度涨到 60 的世界会进「封存」层
- C. 自动保存，无手动存档——每轮回判即落库，中途强退不丢，重进续玩~

# 十二. 帷境

> 🙌 桌面主屏底部那条通栏。一个**私人剧本档案馆**：你写一部只属于这部作品的故事，可以有 TA 出场、可以生成正文、可以邀请 TA 来共读。它的三条底线刻在门上：**默认私密、默认非正史、默认人物不知情**~

## 1. 开帷五步（新建故事）

- **① 取景** —— 选孤岛/群岛 + 来源岛
- **② 出场人物** —— 候选池含大号/皮套/NPC；点标签换 主角/配角/出场；**user 位置三档**：作为人物出场 / 幕外旁观 / 完全隐去
- **③ 现实** —— 作品性质三档：**普通故事 / 平行世界 / 正史候选**；时间落点；**取材三档**：不读取 / 只读关系与性格底色 / 读取当前世界资料。固定边界写着：「出场人物均不知情；作品保持未定；不会写入正史」
- **④ 试读确认** —— 文风设置 + 确认单 + 封条，确认后开写

默认值刻意选「最不动现实」的组合：普通故事 + 完全隐去 + 不读取~ 新建即存草稿，中途退出在门厅「未开帷草稿」接着弄

## 2. 写正文

- A. 章节可以「**规划章节**」（AI 拟 3~8 章，仅零章时可调）或直接写第一章；之后一章章往下写
- B. 阅读页点任意段落可「**重写此段**」（换一种说法/更克制/更有画面…快捷选项 + 自由说明）——**只改这一段，旧版留在修订里**
- C. 章末会出**岔路**（最多 3 个选项），你选哪条下一章就沿哪条写；右上「手记」写给下一次生成看，不动已写正文
- D. 生成走模型（设置→副 API 勾「帷境」可分流，没勾走主 API）；同章并发有闸，取消/失败都是干净状态可重试

## 3. 文风

- **A. 六套底座**：静水 / 近火 / 行旅 / 群像 / 冷镜 / 夜谈，四根滑杆（叙述距离/语言密度/叙事节奏/对话占比）随便调，改过即成「自定义」
- **B. 全局文风只是「新作品的起点」**：开帷那一刻快照进作品，之后改全局不影响老作品~
- **C. 雷区**：禁写规则四档强度；新规则**先进候选区，点「确认生效」才参与检查**——一次误判不会永久污染全局

## 4. 成稿检查

**0 API 纯本机文本检查**，五层：人物逻辑（代理检查）/ 明确禁用（括号动作、套话）/ 高频意象 / 句式模板 / 段落模板，外加跨章风格漂移和人物声音差异提醒。

> 它**只出报告，不擅自改你的正文**。干净不等于没有问题——逻辑与声音最终要靠你自己读~

## 5. 共读（邀请 TA 一起读）

- A. 前置：已有写好的正文；一部作品同时只有一个进行中的同席
- B. **邀请是发到聊天里的**：TA 自己判断接受 / 改天 / 只收下 / 婉拒（带一句 TA 自己口气的话）。⚠️ 邀请卡上的按钮**不是给你点的**——那是 TA 的回应区，你点了就是替 TA 决定啦
- C. **陪读方式三档真的改变行为**：安静陪读 / 偶尔回应 / 自由畅聊。「询问反应」会让 TA 作为**读者**说两句感想——沉默也是合法回应；冷却 3 分钟
- D. 结束同席生成台账：**REAL（共读事件，可以成为现实）vs STORY（剧本内容，不会成为现实）**并排摆着。唯一现实候选是「你与 TA 共同读过《…》」——存进留痕后**你确认才生效**

## 6. 谢幕与五路去向

「谢幕」是唯一能把作品标「已完成」的入口，之后五条路彼此独立：

**① 保存票根**（进收藏馆，一部作品一张）**② 分享给一个人**（TA 读完可以回应，不算共读）**③ 邀请同席共读** **④ 公开到论坛**（占位，暂未开放）**⑤ 进入正史审阅**

> 底注永远写着：**收藏不等于分享；分享不等于共读；共读不等于定史。**

## 7. 正史审阅（唯一把故事写进现实的地方）

- A. 只有开帷时选了「**正史候选**」的作品能进审阅（普通/平行世界会被拦：「它在开帷时就承诺过不进入任何人的现实记忆」）
- B. 候选事实一条条列出来，**每一条都要你亲手确认**——确认后才写进 TA 的现实记忆（进留痕，走待确认流程）
- C. 三条红线再念一遍：**创作取材 ≠ 人物知情 ≠ 现实写回**。你在故事里用了 TA 的记忆，不代表 TA 知道这个故事存在~
