# 设定仓库 · 方案卡（重设计输入）

> 给宝宝的页面重设计底稿。下面「红线/约束」动不了，「自由区」随你画。
> 现状依据：docs/方案-设定仓库-v1.md + 实际落地的 page-repo.js / repo-core.js / worker/。

## 0. 一句话定位

小手机里的「设定分享站」：把自己岛里的角色 / 世界 / 预设 / 以身入局 / 美化 / 整岛
**打包上传**，别人用**门牌口令**进圈、领取、导入进自己的岛。
本地优先的招牌不动：**设定包正文永不过我们的服务器明文**（盲盒锁只在本地解密）。

## 1. 已定红线（动不了，动了要和 Worker 对齐）

- **六类包**（sleepy 自有格式，明确不收酒馆/SillyTavern 卡）：
  角色卡 / 世界书 / 预设 / 以身入局 / 美化 / 整岛包
- **锁级**：`公开`（明文可用） / `盲盒`（上传前本地加密，下载后 UI 只显标题+摘要+封面，
  不可看原文、游玩时本地解密注入）。**不做代持**——服务端不拼提示词、不存明文。
- **头像 / 媒体 = URL 制**：打包不带任何图片；角色/岛头像由分享者填 URL，
  留空 = 字母脸；展示失败回落字母脸（offline 不炸）。
- **整岛包边界**：不带聊天记录 / 朋友圈 / 日记 / 照片 / 马甲 / API 配置；
  美化 + 世界书 + 预设 **可选带入**（向导里逐项勾「用我的 / 带包里的」）。

## 2. 后台（P0 已上线）

- Cloudflare Worker：D1（`items` / `gates` / `authors`）+ KV 存包体（单件上限 5MB）。
- 仓库 API 域名**烤死**在代码里（`DEFAULT_BASE`，页面无填写框）。
- **门牌 = 口令**（`gates` 表）：没口令 = 看不到任何货架内容。
- 作者令牌：发布时生成、存本机；丢了 = 无法再管理该件（方案里写明，不找回）。
- 行为元数据（点赞 / 评论 / repo / 甜度）上 Worker；**设定包正文永不过服务器**。

## 3. 信息架构（四个 tab）

```
[ 货架 ]   [ 我的 ]   [ 门牌 ]   [ 我 ]
```

- **货架（发现）**：按当前门牌看卡片流 = 封面 / 标题 / 作者 / 类型标签 / 锁标 /
  领取数 / 更新时间；类型筛选 + 关键词搜（搜索 P2）。点一件 → 详情 sheet →
  「领取并导入」。
- **我的**：
  ① 打包发布向导（类型 → 选件 → 门牌码 / 署名 / 头像 URL → 发布）
  ② 我上架的（下架 / 版本更新，同 id 重传）
  ③ 我领取的（已导入记录、可重导 / 删除）
- **门牌**：口令 / 链接输入框 + 「粘贴识别」按钮（抠出 `?g=` 码）+ 进过的货架列表
  + 一键复制分享链接 `…/repo/?g=<码>`。
- **我（资料 + 头衔）**：资料卡（昵称 + 头像 URL，**只用于仓库署名和门牌分享卡**）
  + 头衔墙（本地推导：开炉掌柜 / 尝过一口；甜度系头衔 P1 点亮，当前显示虚线占位）。

## 4. 关键链路

```
打包（从岛挑件）
  → 发布（Worker 落 items + KV 包体，回作者令牌）
  → 门牌（口令 / 链接传播）
  → 货架（持口令者可见）
  → 领取（下载 item）
  → 导入向导（整岛包：选美化/世界书带不带 → 生成新岛、用自己马甲；
             角色卡：进当前岛）
```

## 5. 试吃 / 甜度 / 头衔（P1 口径，已定调）

- **不叫「欠」、不搞催债脸**，包装成「试吃 → 投喂」的口味：
  - 作者设门槛时，user 看到的是软话：「如果给 xxx 老师一个 repo，她会很开心，
    您也会获得一点**甜度**」。
  - 作者勾「必须 repo」→ 领取前**事先告知**，不事后设卡。
  - 宽限提醒语气：**「您的试吃时间快结束啦，要不要用美味 repo 换美味作品呢~」**
    （按钮是「去交 repo」，不是「去还债」）。
- **甜度** = user 信用值：交一份 repo +1；逾期未交该作者可冻结领取，
  措辞是「这位老师的试吃名额暂时满了」——系统不说教、不公示、不排名。
- **头衔**：创作者系（开炉掌柜 / 头号试吃官 / 回头客最爱…）+ 使用者系
  （尝过一口 / 小甜豆 / 甜品常客 / 从不放鸽子…），**只升不降**。

## 6. 当前进度

- **P0 全通**：Worker 线上 + 仓库 App（角色卡 / 整岛包两种件）+ 门牌链接卡 + 识别 +
  导入向导。
- **P1 待做**：盲盒锁（本地加密 + 锁定 UI）、世界书 / 预设 / 以身入局 / 美化四类件、
  试吃解锁 + 甜度服务端记账、头衔墙服务端点亮。
- **P2**：搜索细化、举报下架、岛内版本更新提示。

## 7. 给你自由发挥的区（视觉 / 交互随便改）

- 四个 tab 的整体视觉与交互节奏（当前是底部 tab + 纸面撞色
  `#f4f0e7` 纸底 / `#1c1a17` 墨线，卡片流偏朴素）。
- 货架卡片的封面与排版、详情 sheet 的层次、导入向导的步骤感。
- 门牌页「进圈」的仪式感、分享链接卡的样式（对外可识别）。
- 头衔墙的呈现（勋章 / 挂轴 / 印章 / 甜品贴纸）。
- 「试吃 → 投喂」的甜品语言怎么落成 UI 文案与动效。

**约束只在**：manifest 数据字段、包类型枚举、锁级语义、URL 头像、整岛包边界——
这些动了要和 Worker 端对齐，别在纯视觉层改。
