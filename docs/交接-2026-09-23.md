## 这一轮踩到 / 用到的四件事（值得记）

1. **`scroll-behavior:smooth` 会接管程序性赋值**。给滚动容器写了 smooth 之后，
   `el.scrollLeft = x` 也变成动画 —— 这就是「进桌面要点半天才点得到图标」的根因。
   以后凡是要**瞬移**，都要先把 `scroll-behavior` 压成 `auto` 再赋值。
2. **`has-img` 是一份手工登记表**，漏一个类 = 那个头像位置永远被首字压着。
   这轮一口气补了 `.me-av` / `.mtb-mini` / `.cs-ava` / `.contact-av` 四个。
   **以后任何新增接了 `core.setAvatarBg()` 的类，都往 `style.css` 那串里加。**
3. **抽屉里的「选项按钮」不能复用 `.iol-drawer-cancel`**。那个类只对
   `.iol-drawer-actions` 底下的按钮定义过尺寸，单拎出来用就退回浏览器默认按钮大小
   （用户看到的就是「按钮超级小」）。新类 `.iol-drawer-opt` 是给选项用的。
4. **报错路径要过「自家网址」闸**：`app.js` 的 `scrubOwnUrl()`，
   只有 `kind==='err'` 才过（正常文案里提线上地址仍然照写）。
