## 二、真机抓到的两个坑（都已修，但值得记）

1. **顶栏下面那条 1px 横线不是 bug 在底图里**
   底图 y150–210 的逐行均值是平滑的（238.6→239.4，无突变）。真凶是
   **`.app-head::after`**（style.css:2507 那条 1px 渐变细线）；而且 `.app-head`
   默认还带 **`backdrop-filter:blur(14px)`**，会把插画最上面一条天空糊掉。
   → **任何「整幅图打底」的页面，都要显式关掉 `.app-head` 这两样**
   （先例：`.page[data-page^="diary"] .app-head::after{display:none}`）。

2. **夜灯下顶栏的标题/返回键/状态栏会翻成浅色**，压在暖白插画上是白字白底。
   光把文案写死不够 —— 标题、返回键也要写死；`#statusbar` 不在 `.page` 里，
   得走 `#phone:has(.page.is-active:not(.is-behind)[data-page="island"]) #statusbar`
   （照抄朋友圈封面那组，style.css:6159）。

> 一句话规则：**插画页的颜色由画定，不跟主题。** 底图永远是浅色，所以这页上
> 所有文字/控件都要写死暖深色，不能用 `--g-ink` / `--g-accent`（夜灯是薄荷绿）。

## 五、文案位置：**按房型各写一份**（2026-09-22 第三次调整，v106）

### 为什么不能共用一个 `top`
两张底图是**分别生成**的，主体在画面里的高度不一样 —— 实测岩尖落点：
| | 岩尖（屏幕 y） | 共用同一个 top 时的间距 |
|---|---|---|
| 孤岛 | **506** | 34px |
| 群岛 | **476** | **54px** ← 用户：「其实群岛看会更明显」 |

所以 CSS 里是两份（`= (岩尖 + 24px) / 844`）：
```css
.isl-page[data-kind="isle"] .isl-word{top:62.8%;}
.isl-page[data-kind="archipelago"] .isl-word{top:59.3%;}
```
`data-kind` 打在 `.isl-page` 上（`page-island.js` 里 `page.setAttribute('data-kind', kind)`）。

### 换图之后怎么重新量
```bash
"C:/Users/wumei/.workbuddy/binaries/python/envs/default/Scripts/python.exe" \
    "D:/tmp/isl-redesign/measure-tip.py" -v
```
原理：主体在横向中间、背景在两侧 → 逐行比较「中间 20% 的均值」与「两侧各 14% 的均值」，
中间明显更暗的算主体行。

**两个必须知道的坑**（都踩过）：
1. **不能直接取「最后一个主体行」**：云影偶尔会凑出一小簇（群岛在 img1535~1544
   有 9 行暗像素），直接取最后一行会把尖尖**读低 120px**。
   → 改成取「**最长的那一段连续主体**」——岛是一整块从树冠连到岩尖的，
   最长段一定就是它。
2. **必须纵向平滑再判**：岩尖是很窄的尖，最后几行只有 3~4 个暗像素，
   不平滑会把尖尖判断。

当前值：孤岛 506 / 群岛 476（脚本 `-v` 可复核）。
