## 1. 数据对象（全部 scoped 到 sandboxId=岛）

新增 store 键（十条，全部要进 removeSandbox 名单）：

- `phones` —— 手机壳：id / charId / wallpaper / accent / appOrder / lock{pin} / knownPin /
  lastExitedAt / bootstrapStatus / settledUntil。**建壳 0 API、幂等**。
- `phonePerms` —— 授权：scope(all/app:xx/item:xx) / mode(once/timed/long) /
  state(open/hidden/revoked/expired) / reason。
- `phoneSessions` —— 进入会话：entryType(peek/invite/longterm) / authorized /
  unlockMethod(grace/pin_known/pin_guess/invite/longterm) / pinFails / actionsSpent /
  riskStage / caughtOnScene / startedAt / endedAt。
- `phoneTraces` —— 痕迹：app / type(read/recent/pin_fail/location/misclick) / detail /
  detectable / detectedAt。
- `phonePlans` —— charPlan：status(brewing/preparing/scheduled/done/paused/cancelled/changed)
  + history[]（变化留痕）。
- `phoneMsgs` —— 派生幕后会话 + 未发送草稿（kind: derived/draft），展示即 confirmed。
- `phoneNotes / phoneBrowser / phoneShop / phoneHealth` —— 备忘录/浏览器/淘宝/健康打卡内容，
  第 3 批填。

三条铁律：① 展示给 user 的内容落库为 confirmed，永不被重生成覆盖；
② 知道密码/获得允许/成功进入三分（三个独立字段，绝不合并布尔）；
③ char 只能凭 detectable 且已被「合理触发」的痕迹察觉，无上帝视角。

## 2. 分批施工

### 第 1 批 · 底座 + 入口 + 桌面（本轮）
- phone.js 数据层（上表 + 幂等建壳 + 会话/行动/风险/痕迹 + 环境提示分级 + 当场判定 roll）。
- page-phone.js：`phonecheck` 入口页（孤岛直取唯一主角色；群岛「谁把手机落在了这里」选人，
  长期授权者标「已向你开放」）→ 锁屏（宽限期直进 / 记得密码 / 猜密码（四位，失败留痕、
  5 次暂锁）/ 收手只看通知）→ 全屏接管私人桌面（壁纸/排列由 charId 哈希派生，非模板）。
- 行动消耗：开 App、进会话、深翻、猜密码都 +1；风险阶段推环境提示；
  剧情强度默认「轻微风险」；当场被抓按位置分流记录（AI 反应第 2 批接）。

### 第 2 批 · 生成链与冷启动
- `phone_delta` 搭载 chat_reply（0 新增）；主动消息搭载（0 新增）。
- `phone_life_settlement`：本地闸门（自主生活档位→阈值表）→ 后台队列 → 一次输出跨 App 增量
  → 程序校验（§10 十二条）→ 事务写入；settledUntil 幂等。
- `phone_bootstrap`：新 char 一生一次初始底片（轻量/只真实/丰富 三档）。
- 模型选择：`phoneApiCfg {mode:'main'|'pick', label}`，照 memoryApiCfg 模式回落主 API。
- char 邀请卡（特殊消息）→ 授权流；权限暂时隐藏/正式收回 UI。

### 第 3 批 · 官方 App（依赖序）
消息（v1 已随第 1 批：镜像+草稿/幕后结构+查看痕迹）→ 淘宝 → 备忘录 → 浏览器 → 健康打卡；
相册读 photos char 侧实例；日历缺口单独补。全部只读本地。

### 第 4 批 · App 工坊
appTemplate / appInstallation / appRecord 三层；六类模板；主入口=第 2 屏「工坊」格；
快捷入口（角色管理 / 手机桌面管理模式）；手动 0 API、AI 辅助显式 1 次。

### 第 5 批 · 联动验收
订单兑现、计划变化、权限隐藏/收回、当场/事后察觉、App 数据进聊天（确定性注入 + 检索）。

## 3. 设置项（用户 2026-09-19 拍板）

- 聊天 char 设置加「自主生活」：关 / 低 / 中 / 高（存 charSettings.byChar[charId].autoLife）。
- 「查手机用的模型」：phoneApiCfg，默认跟随主 API，可指定副 API（同 memoryApiCfg 语义）。
