- 现在：`appendBatch`（page-we.js:1130 附近）在 `listEl.appendChild(card)` **之后**取 `card.querySelector('.we-time-thumb')` 再调 `fillThumb`；构建期不发请求。
- 异步回来检查 `img.isConnected`：重画 / 切岛 / 切上下文后旧节点已摘除，旧响应改不到新视图；失败（图不在）保持纸纹占位不加 `has-img`。
- 测试（browser **W23** ✅）：canvas 造真图 → `media.put` → 朋友圈带图 → 时光缩略图 `has-img` + `backgroundImage` 非空；`mediaId:'media-nope'` → 占位不加载；切乙岛刷新后新视图无旧图残留、回甲岛恢复。

## 4. 可见性判据统一 + 共享边界

- **抽取共用判据**（page-we.js:849-901）：`momentVisibleToUser(m, char, user)`、`diaryVisibleToUser(d, char, user)` —— `timeItems`（列表读取）与 `sourceStatus`（点击复核）调用**同一组函数**，不再各写一份。
- `sourceStatus(src, id)`（page-we.js:881）返回 `'ok' | 'gone' | 'denied'`：实时回源（byId / diary.list / findInScope）+ 当前岛 / 角色 / 号 / 状态 / 权限全查；**上下文缺失或权限接口缺失一律 `denied`（fail closed）**；`jumpToSource` 按 gone/denied 给不同反馈（「已经不在了」/「现在这个身份看不到它了」），都不跳页。
- 测试：browser **W24** ✅（新）——u1 视角渲染列表 → 切到 u2 不刷新（残留 DOM）→ 点旧条目 → toast「现在这个身份看不到它了」、top 仍 we-time；刷新后聚合层排除。smoke「时光 v1.1」✅——`sourceStatus` ok/gone/denied 三态断言（TA `privacy:'self'` → denied）。
- **weEntries 共享边界（证明，不改权限）**：weEntries 只盖 `sandboxId`（岛章），`refCharId/refUserId` 是归属档案**不是 ACL**——同岛多角色 / 多账号共享全部记录，是产品既定口径（weEntries 主表 scoped 过滤，拍板 §一）。smoke「时光 v1.1」实证：`(m1,u1)` 写的记录在同岛 `(m2,u1)` 下 collect 可见。**core.scoped 的岛过滤 ≠ 关系过滤**，本轮未收紧、未扩大。
