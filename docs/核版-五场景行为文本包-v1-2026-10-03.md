## 0. 三个先行结论

**结论一 · 本包五段与现有卡不是"替换关系"，是"重新切分"关系。**
包内五场景 = `B + P + L + (E|N) + S#`。现有代码里**没有任何一个模块叫 B/P/L**；
承担相近职责的是**共享外壳（shell，7 节）**与 **F1 / F2 / proactive / groupRound 四张场景卡**。
shell 的职责面比 B **更宽**（多出[角色声音][主动与节制][输出]），且与 P、L 大面积重叠。
→ **[源码证据]** 包 §1 明令"禁止完整 shell、完整 F1/F2 与本包未经去重直接叠加"，
所以迁移的**第一步是逐节去重表**，不是替换卡文本。

**结论二 · 五场景的装配实现是五份独立代码。**
| 场景 | 装配函数 | 文件:行 | 出站形态 |
|---|---|---|---|
| 私聊线上 | `assembleOnline` | `prompt-engine.js:1091-1173` | **多条 system** + history |
| 私聊线下 | `assembleOffline` | `prompt-engine.js:1368-1478` | 多条 system + history |
| 主动消息 | `buildSystem` + `evaluate` | `page-proactive.js:197-215` / `217-266` | **1 条 system（`\n\n` 拼）** + 1 条 user |
| 群线上 | `composeRound` | `page-group-ai.js:182-281` | **1 条 system（`\n\n` 拼）** + 1 条 user |
| 群线下 | `buildSystem` | `page-group-offline.js:192-340` | **1 条 system（`\n\n` 拼）** + history |

跨场景**唯一共用**的编译实现只有两处：`charMetaLines`（短字段）与 `langOfChar`/`transAsked`（语言）。
→ **[源码证据]** 行为文本迁移必须**逐场景落**，且新增装配处一律复用现有唯一实现（不得各处另写）。

**结论三 · 对上一轮盘点的一处更正（主动消息未注入 TA_IMPACT）。**
上一轮矩阵把 S17「ta 已成立影响」的主动消息列记为 ✅ `:324`。**该行号不是注入点**：
`page-proactive.js:324` 位于 `noteTaOutcome`（`:323-340`），内容是 `ti.noteProactive(...)` ——
**判断结果回写 ta 提案**，与 `[TA_IMPACT]` 文本注入无关。
全库 `compileTaImpact` 只有两个调用点：`prompt-engine.js:1139`（线上）、`prompt-engine.js:1417`（线下）。
**主动消息的 system 段不含 K03d**（`buildSystem:197-215` 全量清单见 §1.3）。
→ 修正后：主动消息的"已成立影响"= **未接**。这正是"要看调用链与最终 messages，不能只看关键词命中"的实例。
