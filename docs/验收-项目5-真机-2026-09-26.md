# 第 4 步 · 失败续扫（failed 状态 → 恢复重试 → 断点不重复算）

2. 种子页 **「⑥ 刷新报告」**，截图，应显示：
   - vecRebuild = `{"state":"failed",...}`（带错误原因）

## 4-C 恢复 → 同一按钮续扫

   块总数 = **与第 3 步持平或略多**（多出来的是你后来聊的）——**绝不能翻倍**

**判定**

- **通过** = 4-B 如实失败且状态保留、4-C 续扫走完、块数不翻倍、提示消失
- **失败 A** = 4-B 假装成功（提示消失但块 0）
