## 换岛语义
- **岛级覆盖 > 全局**：穿着叠 `appearance.desktop.islands[sbId]`、户型叠 `desktop.islands[sbId]`（含 theme）。
  apply/applyDesktop 永远「有岛覆盖用岛覆盖，否则全局」，**没有第二道开关**。
- **孤岛一打开就是那个 char；群岛先选 char**。设置类 app 例外（设置/外观/浮岛/商城/预设/工坊）。
  选人+卫兵的**标杆**是 `page-calendar.viewSyncSandbox`；选人范围：日历/查手机/帷境。
- **岛屿之间隔绝往来**；char 与马甲**全部按岛**（upsertChar/upsertUser 打当前岛章），拆岛连人清；
  `ensureDefaultUser` 的兜底「我」**故意不打章**。
- **房间管理只有一个入口 = `island-overview`（岛屿总览）**。配置台 `island-config` **2026-09-22 整页删除**
  （用户：「又要进入岛屿设置，没必要啊，岛屿设置不能删掉么」）——它的内容：人物/加人设/导入人设 → 总览
  「核心成员」；马甲 → `mask-list`；认知锁 → `island-cognition`；拆岛 → 总览底部。
  `smoke.js` **反向断言它不许再注册回来**。
- **马甲管理 = `mask-list`，必须带 `sandboxId`**。人不在那座岛时点一行 = **定「进入身份」不许切号**
  （切了 `activeUserOnIsland()` 当场 null → 聊天列表整个空）。**新建马甲要进 `sb.maskIds`**（否则
  `masksOfSandbox` 看不到它）。
- **两个指针卫兵** `core.activeCharOnIsland()` / `activeUserOnIsland()`：当前身份必须是**本岛**名册里的一件，
  否则 null。「跟当前身份走」的读写一律走它们；别直接 `activeChar()`/`activeUser()`（有跨岛兜底，就是旧指针来源）。
  不挂的后果（真出过）：落岛后聊天列表整个空、新建会话把名字挂到上一座岛。
- **「我」的大号 = `sandbox.maskIds` 里标 `isDefault` 的那件**（每岛唯一）：`defaultUserOfSandbox(sb)` 取；
  `setDefaultUser` 同岛互斥别岛不动；`removeUser` 删后本岛第一件顶上；**降落一律归位到本岛大号**。
- **user 名字可以留空**（2026-09-22）：显示与注入的**唯一出口** = `core.labelOfUser(u, fallback)` /
  `core.initialOfUser(u)`（name → wechatName → fallback，**只影响显示，不回写存档**）。
  `upsertUser` 新建分支必须 `has(data,'name')`，**不能用 `||`**（会吃掉「显式留空」）。
  注入侧（`compileI01` / `compileUserCore`）也走它，否则模型面前的人变成空串/`?`。
- **desktop 写路径**只能走 `Sleepy.desktop.setDesktop(d)`（直接 `store.set('desktop')` 写穿层），读走 `getDesktop()`；
  sandbox 上不再有 theme/deskVersion/pages。**换岛必须重放视觉**（`land`/`landInto` 里喊 `appearance.apply()`）。
- 国籍 ≠ 常住地：三件套（city/region/timezone）管一切计算，国籍只显示 + 文化默认，永不计算。
- 酒馆(SillyTavern)世界书格式**不做导入**，一律拒收。

## 「我」页（聊天 App 第 4 屏 · v90）
- 仿微信平铺：hero（当前账号 → 点整块进 `me-profile`）→ 小字（本岛大号/小号 · 在不在当前岛）→

  `--g-accent`/`-deep`/`-soft`/`-pale`；占位圈 `linear-gradient(140deg,#F7F2EA,#EAD9C2)` + 首字 `#8A6844`。

  `border:0;background:none;padding:0;font:inherit;cursor:pointer`。

  解释塞 placeholder，别加回圆角框/解释行）；**头像入口全站只有一个形状 = `Sleepy.faceField`**。
- **同一个默认值别定义两份**：改默认值前先确认「这条回落链上谁最后说话」（生成参数只认 `api.js` 的
  `GEN_DEFAULTS`；上下文条数唯一出口 `Sleepy.api.contextLimit(chat)`）。

## PWA / 加到桌面
- **`sw.js` 铁律**：① `respondWith()` 绝不能拿到 `undefined`（Chromium 里 = ERR_FAILED + 白屏零报错），
  兜底三级 `index.html` → `'./'` → `offlineShell()`；② `install` 逐个 `add`（别 `addAll`）；
  ③ install 期必须 `warmShell()`（读 index.html 正则出资源主动灌，不写死清单）。
- **测 SW 必须跑线上地址**（index.html 有 localhost 不注册护栏）；模板 `D:/tmp/verify-sw-offline.js`。
- 图标**不能烤圆角**（`purpose:"any maskable"`）；`theme-color`/manifest 跟纯白 `#FFFFFF`；
  装成正经 PWA 要从 `https://sleepy-u17.pages.dev` 装。
- 改样式/脚本后 `sw.js` 的 `CACHE` 跳一位（**当前 v111**）；真机前清一次 SW 缓存。

## 桌面 / 主题 / 挂件灯
- `LAYOUT_VERSION` 当前 **16**：改 defaultDesktop 必须 +1 并实跑迁移（岛覆盖层跟着版本走）。
- 主题 id（grape/night/peach/sea）是存档键**永不改**；新增浅色专属变量要在四主题块各补一份。
  夜灯是**深主题**：铺浅色壁纸也按「深底」走 + 压暗纱。

- **桌面 home 是常驻底层**：重画喊 `Sleepy.__homeCtx.repaint()`，`nav.open('home')` 是空操作。
- **组件商城 = 默认户型收的型号 + `page-widgetstore.js` 的 `EXTRA_DEFS`**；上架前先验证「装得上」
  （默认户型 4 屏没有 1×2 空位）。

## 语义红线
- **「user 能看到的」≠「角色能看到的」**（v99 授权模型，别新造框架），每源各有判据、**优先复用已有字段**：
  · **朋友圈**三道闸：⓪账号隔离（只对 user 视角生效）→ ①朋友权限（四字段 `iHideChar`/`iHideFromChar`/
    `charHidesMe`/`charHidesFromMe` 的方向最容易写反，语义见 core.feedPermOf + 聊天设置页）→
    ②动态自己的 `privacy`。char 视角另判 `canCharSee`（朋友权限闸只对 `kind==='user'` 判）。
  · **日历**：每条事件自带 `visibility` 四档 + `createdBy`，**不要另开全局开关**；`shared_busy` 只给
    「那会儿有事」且措辞要明说「你并不知道具体是什么」。`char_schedule` 是背景，不进 L1.5。
  · **日记**：`author:'char'` 天然可见；`author:'user'` 默认关，开关存 `lifeShare:<charId>`。
- **L1.5 近期生活动态**（`life-feed.js`，槽 K03b）：注入里那句「不必逐条回应，也别当成刚刚发生，
  已经聊过的就不用再提」**不能删**（防「追踪感」，不是行程播报）。
- **L4 向量记忆**（`memory-vec.js`，槽 K03c）：IndexedDB 存索引；写 sweep 不挡聊天、读 prefetch 超时 1.5s；
  重排只动 `rank()`；块里存原文；不回落主 API。`assembleOnline/Offline` 是同步的 → 三处
  （线上/线下/主动消息）都要**先异步预取再装配**。
- **装配五处，只有两处走槽位矩阵**：线上/线下私聊走 `assembleOnline`/`assembleOffline`；
  **主动消息 `buildSystem` / 群聊 `entityKnowledge` / 群线下 `buildSystem` 各拼各的**。
  K01 唯一实现是 `promptEngine.compileCharacter`/`charMetaLines` —— **新增装配处一律复用它**
  （「一张表 + 若干手拼」的结构，手拼处已经漏过两次）。
- **索引里的原文 = 给模型看的证据**：删消息/编辑正文/撤回/删对话一律 `memoryVec.forget`（按 `msgIds` 命中），
  **不做重切**；删改消息一律走 `chatStore.dropMessages`/`patchMessage`，别在别处 filter。
- **记忆系统地图在 `docs/说明-记忆系统地图.md`**（九层在哪 / 存储键 / 槽位表 / 判据）。
- **聊天发送键是两义的**：有字 = 只发不回复；**空着点** = 让角色开口，提示词按上一条是谁发的分流
  （`proactiveHintFor`）；改这里要同步两处注入点。
- **一条对话的坐标是 `(characterId, userId)`**；找会话一律走 `Sleepy.chatStore.chatOf(charId)`，
  别自己写 `characterId ===` 的循环（小号会掉进大号的对话框）。
- `link.relation`（我 × TA 那句关系）**是只写不读的死字段**（唯一写入口随配置台删了）——
  别和 `slot 'relation'`（记忆认知层）搞混。
- 换岛 = 换数据 + 视觉；岛内身份只换 activeCharId/activeUserId；NPC 归整岛。
- objectURL 活不过刷新，进存档只存 mediaId；新存档键要进 core.js 的删房名单（scoped 按岛清）。
- 时间唯一出处 `Sleepy.calendar.timeFacts(charId)`（槽 I02），别处不许手写日期。
- 翻译：语言从常驻地点推（`calendar.langOf`）；线上 `[译][/译]` 按 `||` 配对；**线下走 dialogue 段的
  `trans` 字段绝不进 text**；唯一实现 `msg-trans.js`。
- 线下 = 连续叙事（段落类型只是排版标记，整轮无 dialogue 零头像块，篇幅 300~450，群线下 `350+190×(n-1)`）。
- **活人感 > 克制**（v84）：宁可让 TA 有点脾气、有点啰嗦，也别演成礼貌的客服。
- 查手机：宽限期停锁屏一屏；hidden≠revoked 都不删数据；健康不做聚合评分；空态走 emptyBlock；
  硬翻掷骰必须提醒「可能会被发现」；密码叙事化。
- 日历：数据包必须 .js（file:// fetch json 被 CORS 拦）；周末补班优先级最高；只内置已公布年份；0 API。

## 语音 TTS（六家可用 · v111；细节在 docs/方案-TTS-v1.md）
- **三层文本边界**：`originalText`（聊天原文，永不带标签）/ `SpeechPlan`（唯一对外形状）/
  `synthesisText`（临时，只进请求）。**标签绝不回写气泡/搜索/记忆/导出**。
  映射只走**闭集白名单**（`EMOTIONS` 11 / `TAGS` 7），映射不到的**回退无标签**。
- **能力挂在「模型」上**（`caps`：performanceTags / speed / textNormalization / maxCharacters）：
  UI 允许了什么，就必须真被当前模型支持，别按服务商一刀切。
- 六家都是**浏览器直连**（静态站没有服务端代发）：Fish `Authorization`+`reference_id`；
  MiniMax `Authorization`+`voice_setting.voice_id`+`output_format:'hex'`（**200 也可能是失败，
  必须查 `base_resp`**）；ElevenLabs 音色在 **URL 路径**、凭据头 **`xi-api-key`**；
  硅基流动/自定义走 OpenAI 兼容 `/v1/audio/speech`；Azure **只吃 SSML**（走 `rawBody`）+
  `Ocp-Apim-Subscription-Key`。接不了的六家（火山/腾讯/讯飞/Edge/OpenAI 官方/阿里 DashScope）
  在设置页里**写清实测原因**，走「自定义 · OpenAI 兼容」中转。
- 错误体各家一个形状 → 统一 `errorMessageOf()` 再进 `normalizeHttpError`，别在调用点自己 parse。
- **拿到外部材料先回源码定位 + 真探测**（可达性 + CORS 预检；Fish 本机被 DNS 污染，要自建中转；
  **不得凭假连接验收**）。`transport` 可注入且按调用优先；真实 fetch 兜底必须存在。

## 开发验证
- `pnpm dev`（127.0.0.1:5173）；改完 `pnpm check` + `pnpm smoke` **必须双绿**。
- **`smoke.js` 末尾的「全页渲染冒烟」必须有**（每个注册页面挨个真 `nav.open()`，拦 `console.error` 的 `[Sleepy]`）
  —— app.js 的错误边界会把 render 异常吞成「这一页出错了」，双绿照样整页崩。
- **DOM 桩的底线**：真实 DOM 里一定成立的性质桩也必须成立（已补 parentNode/firstChild/lastChild/nextSibling、
  `appendChild` 的**移动语义**，漏了会死循环）。
- **无头桩过 ≠ 真机能看**（纯 CSS 状态 / 闭包 ReferenceError / DOM 漏 append 只有真机抓得到）：
  playwright-core 在 managed node workspace，浏览器系统 Edge，脚本/截图放 `D:/tmp/`。
- **改代码前先读注释**（用户反馈编号常写在注释里）；**批量替换必须带足上下文并断言命中次数**；
  用脚本换一段代码前先把「要删的那段」打印出来。
- **游标/进度指针都不要只存下标**（删一条就静默错位），存「最后处理过的那条记录 id」。
- **状态标记分三层写**：基础设施 / 链路已通 / 端到端待验收 —— 别把「链路通了」写成「✅ 已完成」。
  **改了实现一定要回改方案文档。**
- `position:fixed` 的层一律挂 `#phone`（或 body），别用 `ctx.el`（`.page` 上有 transform → fixed 退化）；
  **跟着搬的还有 CSS 变量**：只定义在 `.page` 上的变量在 `#phone` 这条链上解析不到（面板会透明/没边框）。
- **新弹层整段抄现成的**（`openProactiveDrawer` 那套）：手写容易漏 `wrap.appendChild(panel)` 和 `.show`，
  只有截图才看得出来。
- 页面实例按 id 缓存复用；**同一 id 不同参数**由 app.js 的 `applyParams` 重渲染；
  `.page.is-active` **不能用来取当前页**（home 底座一直挂着 is-active）→ 用 `[data-page="xxx"]` 或 `Sleepy.nav.top()`。
- 真机造数据：群岛 kind 是 **`archipelago`**；**孤岛（isle）只能有 1 个角色**（多人必须开群岛，否则
  `setSandboxChars` 失败 → 名册空 → 桌面「还没有角色」）。
- 默认户型 v16 **没有情绪印章和角色卡**；测 skin/cycleMood 先往覆盖层塞一枚 `type:'mood'` 格子。
- style 色值会被规范化（`#2C3538` 读回 `rgb(44, 53, 56)`），断言别写 #hex；
  无头桩判类型用 nodeType；`ui.h()` 第三参纯文本，SVG 走 innerHTML；`store.get` 是深拷贝。
- 页面 id 是循环注册的（`chat-list`/`moments`/`me` 同一壳）—— grep `register('app'` 找不到。
- `ctx.setActions` 吃 `{label,onClick,kind?}`；`core.setSandboxChars` 校验全是 main（NPC 不能直接传）。
- `chatStore.createChat(name, characterId)` 参数别反；`char.faceLock` 不存在，走 `imggen.faceTextFor`。
- **部署**：Cloudflare Pages「sleepy」→ **https://sleepy-u17.pages.dev**（分支 main）。
  `git archive --format=tar HEAD | tar -x -C <副本>` → `wrangler pages deploy <副本> --project-name sleepy
  --branch main --commit-dirty=true`。仓库 `git@github.com:9x-Art/sleepy.git`（SSH），**推
  `git push origin master`**。**本机沙盒会神秘删 .git**（已两次）：init + fetch + `reset --soft FETCH_HEAD`。
