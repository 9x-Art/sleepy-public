# 十. 工坊

> 🙌 工坊是你做小东西的地方——做好**装进 TA 的手机里**，装给几个人就各自独立记各自的。全程 **0 次模型调用**~

## 1. 先知道的几件小事

A. 桌面第 2 屏进入

B. 三层结构：**模板（你做的）→ 安装（装给谁）→ 记录（TA 自己记的）**

C. ⚠️ **内容是 TA 写的，不是你写的**——工坊里没有「替他加记录」的入口；你能做的是做模板、安装、卸载

## 2. 六种内置模板

| 类型 | 玩法 |
| --- | --- |
| ✎ 日记型 | 一天一页：日期 / 标题 / 正文 |
| ◉ 打卡型 | 每天一笔：日期 / 事项 / 完成了没 |
| ❋ 收藏型 | 名字 / 为什么喜欢 |
| ▤ 进度型 | 在做什么 / 到哪儿了 / 备注 |
| ❏ 档案型 | 一个人或一件事：名字 / 详情 |
| ⋯ 时间线型 | 什么时候 / 发生了什么 |

内置模板跨岛可用、**删不掉也改不了**~

## 3. 自建模板

选类型 + 起名（≤12 字）+ 一句话描述（≤40 字）+ 强调色。⚠️ **模板名就是钥匙**：模型往这个 App 里写内容时认的是模板名，名字对不上就静默丢弃，所以起名别乱改qwq

删除自建模板会**连带撤掉所有装出去的实例**（记录归档不删，但手机上看不到了），弹窗会提醒你~

## 4. 装给谁

A. 「装给谁」抽屉勾选角色（默认全选、可多选），**每勾一人 = 一份独立实例，记录互不同步**

B. 同一部手机同一模板装不了第二份

C. 装完去 TA 的手机桌面就能看到新图标（官方 App 排在后面）

D. 卸载：记录归档保留，只是手机上不再出现——数据不会悄悄消失~

## 5. 容易疑惑的点

A. **贴纸工坊不在工坊里**（在收藏馆）；**自制桌面组件也不在**（在组件商城）。工坊只做上面这六类

B. 在查手机里看这些自定义 App 是纯只读的，没有刷新按钮

C. TA 记的内容（或结算生成的）都标着来路，展示即生效、不会被后续生成覆盖
