## 身份逻辑实现（user 点名要核对的）

- **user 大小号**：`masksOfSandbox` 每件马甲 → 独立论坛账号；默认马甲 = main，其余 = alt；当前身份存 `selectedForumAccountBySandbox[sid]`，切岛独立恢复，失效回退 main；大小号互不公开关联（我的页身份列表仅自己可见）。
- **char 大小号**：只给 `charsOfSandbox`（房成员=大号）建账号；**皮套不直连论坛**（施工单 §B-1），发言以大号身份出。
- **NPC**：`npcsOfRoom` → resident 型账号；公共居民由 forum-gen 生成（ownerEntityId `gen:名字`，与真实 NPC 区分）。
- **孤岛/群岛**：全部读写过 `sandboxId` 过滤；上下文解析显式参数 > 页面锁定 > 当前房；生成 prompt 只喂本岛角色与 NPC。
- **匿名**：同帖主楼+楼主回复同一别名（hash 键含 postId），跨帖不串联；公开投影无 `accountId/ownerEntityId` 字段（冒烟断言盯死）。

## 活人感实现

种子帖 minutesAgo 5~2880 错落 → 社区有历史；每帖评论 0~4 条且允许没人回；char 帖 ≥2、匿名树洞 ≥1 由 prompt 约束；user 发帖/回复后 4s 自动触发一次回帖生成（静默失败留给手动「催一下」）；详情页「催一下」60s 冷却；首页「催更」= 补种子（幂等跳过已种）。

## 已知边界 / 风险

1. 「阅读数」和首页「第 N 期」是 hash 出来的展示值（demo 有此视觉，无真实数据源），已在代码注释标注；后续接真实浏览记录时替换。
2. `msg.link` 分享卡、公开转帖、朋友圈引用 = Batch C；通知未读 = Batch D；帷境/图片/认知 = Batch E。
3. 无 API 配置时首页/详情都有「催更/催一下」降级提示，社区保持空态不伪造内容。
4. 真机验收清单（用户跑 `node serve.js --lan`）：孤岛/群岛各进一次 → 首页「催更」生成种子 → 发匿名帖 → 详情「催一下」→ 刷新持久 → 切岛内容不串 → 删岛 forum 数据清空。
