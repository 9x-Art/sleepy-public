# 验收 · 孤岛/群岛马甲真隔离 + 彼此认知档位一致 · 2026-10-03

## 一、用户反馈（原话）

> 本身点进孤岛就会有一个默认存档，改了之后再加孤岛或者群岛都直接挂钩那个存档，
> 表单完全 copy 过去了，并且后面改了孤岛 B，其他所有岛屿的 user 账号信息都变了！
> 要隔离！！不是一个啊，而且为什么默认存档的"彼此认知"和新加的岛屿里"彼此认知"不一样，
> 一个有选项，一个没有

## 二、结论：`core.js` 是清白的，病根全在 UI 层「拿人」的方式

先做了一件关键的事：**先证明数据层是好的**。
冒烟里加了两条**数据层**用例（一条查马甲隔离、一条查认知值域），**当场就绿了** ——
说明 `core.js` 的按岛隔离、指针卫兵、`defaultUserOfSandbox` 全都是对的。

于是把范围收窄到 UI。四处病根，全部是「编辑页怎么取人 / 怎么存人」：

| # | 位置 | 病根 | 症状 |
|---|---|---|---|
| ① | `page-idcard.js` `me-profile` | 用 `core.activeUser()` 取人，那个口子带 `\|\| ensureDefaultUser()` 的**跨岛兜底** | 新岛打开「个人资料」，表单里是别座岛那件 → 用户看到的就是「copy 过去了」；在这里改名 = 改别座岛的记录 → **全岛跟着变** |
| ② | `page-idcard.js` `mask-edit` | 只按 `id` 全局找记录，**不校验归属** | 跨岛打开会把别岛的记录整个 copy 进表单 |
| ③ | `page-switch.js` 切换器「新增马甲」 | `open('mask-edit', {id:''})` 没带 `sandboxId` | 在别的岛开着切换器时，建出来的是别座的马甲 |
| ④ | `page-idcard.js` `me-profile` `doSave` | 不传 `sandboxId` | 传 `undefined` 会被 `upsertUser` 的 `has()` 判成「显式给了空」→ **把岛章抹掉** |
| ②' | `page-island.js` `island-cognition` | 认知锁整段挂在 `mains.length && masks.length` 底下 | 新岛没马甲 → 整段不渲染 → **「一个岛有选项一个岛没有」** |

④ 是这轮顺手挖出来的：它藏在 ① 后面，修了 ① 才会暴露。

## 三、修复

- **①** `me-profile` 改走**指针卫兵** `core.activeUserOnIsland()`（与 `page-switch`/桌面同一把尺子）。
  戴的不是本岛的人 → 明确提示「这座岛还没定『我』是谁」+ 不给表单，**绝不**拿别岛的人当初值。
- **②** `mask-edit` 补岛归属闸：记录不属于要编辑的那座岛 → 直接拒（fail closed）+ 提示。
  宁可让用户重新点一次，也不给跨岛的编辑口子。
- **③** 切换器「新增马甲」补 `sandboxId: sb.id`（那一屏上下文已经是这座岛）。
- **④** `me-profile` 的 `doSave` 显式回写 `sandboxId: u.sandboxId`。
- **②'** 认知锁门槛从 `mains && masks` 改成**只看 `mains`**。
  档位是产品常量（`LOCKS` 四档：拼图局/调情局/死装局/没有小号），与此刻有几件马甲无关。
  马甲数为 0 时改成：四档一条不少地列出来 + 说清「去『进入身份 · 新建一件马甲』加一件」。

## 四、护栏：三层，都有负向对照

### 1. 数据层（smoke，两条）
- `马甲真隔离：一件 user 记录只属一座岛，改一件不影响别岛`
- `彼此认知：新岛没马甲也要给出同样的档位`

### 2. 静态层（smoke，一条）
`跨岛隔离静态护栏` —— 扫源码卡四个点（取人必须是卫兵 / 归属闸 / 切换器带岛 / 认知锁门槛）。

### 3. 真机端到端（新脚本，14 项）
`scripts/browser-island-isolation-test.js` —— 真系统 Edge（headless、一次性 profile）+
生产源码原文，走 `nav.open('me-profile')` / `nav.open('island-cognition')`
**真页面真点击**，验「用户实际看到什么」。

### ⚠️ 负向对照（这轮最要紧的一课）

四处修复**逐个退化**，全部被抓：

```
退化① me-profile 改回裸 activeUser()
  ✗ me-profile 取人用的是 var u = core.activeUser() —— 必须是 activeUserOnIsland
退化② mask-edit 归属闸失效（if (false)）
  ✗ mask-edit 只在文案里提了「不属于这座岛」，代码里没比 sandboxId
退化③ 切换器去掉 sandboxId
  ✗ 时空切换器「新增马甲」没带 sandboxId
退化④ 认知锁门槛加回 masks.length
  ✗ 认知锁又回到「有马甲才渲染」了
真机侧同④退化：
  ✗ ② 没马甲的新岛也给出同样四档  缺：拼图局/调情局/死装局/没有小号
全部还原后：✓ 全绿
```

**第一版护栏是假绿的**（四次退化一个都没抓到），原因值得记：
护栏扫全文时，**修法说明的注释里必然要写出旧写法那几个字**
（说明「原来用的是 `core.activeUser()`」），于是注释自己把违规判成违规 ——
第一版因此一直在第一道 `indexOf` 就放行，真正的 `forEach` 根本没走到。
改成**先剥注释再扫代码**，并把判据从「有没有出现某串字」换成
「赋值语句里到底调了哪个函数」/「代码里有没有比 sandboxId」，才真正抓住。
另一个同类坑：锚点用 `indexOf('初始认知锁')` 会命中**文件头文档**里那几个字，
窗口落到完全无关的地方 —— 锚点必须用真正的渲染调用 `secTitle('初始认知锁')`。
