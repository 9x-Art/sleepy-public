## 一、浮岛

### 浮1 · 补了头像但是 user 看不到
- **原话**：「补了头像但是现在这样user看不到qwq」
- **现状**：第 15 批把 `avatarFieldLocal` 接进了编辑**表单**（能存 `avatarMedia`），但浮岛这边的**显示端**全是 `avatarLetter()` 首字母色块 ——
  `page-island.js` 总览 `personNode()`(1415)、NPC 卡(1322)、`island-char` hero(1578)、`identityCard()`(1717)、配置台关系树 `person()`(970，SVG 里也只有首字母)。
- **结论**：`[可做]` 浮岛所有头像位接 `core.avatarSrc/setAvatarBg/setAvatarImg`（第 14 批的口子）。**拍板：做。**

### 浮2 · 编辑页 + 选岛页配色/美观
- **原话**：「建议宝宝用上skill重新设计下编辑页和选择孤岛与群岛的页面，因为感觉配色不好看，然后那两个岛屿也不是很美观」
- **现状**：`isl-stage` 是一块 376×120 的扁平淡绿椭圆 + 两棵棒棒糖树（孤岛）/四个淡绿椭圆（群岛），stage 无背景（`backgroundImage:none`），整页大量留白、对比度极低。
  编辑页 = `contact-edit` 的 `renderSimple()`（page-idcard.js:375）。
- **结论**：`[方案]` **拍板：画精致，配色也改，总体优化设计**（「其实我们别的app什么的都还蛮好看的」—— 向其余 App 的水准看齐）。用 finesse-ui 做。

### 浮3 · 键盘压住输入框
- **原话**：「不抢键盘了，但是现在点击输入框后键盘压住了输入框，要输入几个字才会上去」
- **现状**：`iol-drawer` 抽屉锚在布局视口底部；手机键盘弹起只缩 `visualViewport`，布局视口不动 → 抽屉原地不动被键盘盖住，浏览器要等输入内容撑高才滚动。
- **结论**：`[可做]` 监听 `visualViewport` 的 resize/scroll，把键盘高度写成 CSS 变量抬抽屉（并 scrollIntoView 聚焦框）。

### 浮4 · 点 char / user 头像无法编辑
- **原话**：「孤岛里有个默认存档，但是点击char和user的头像都无法编辑，还有就算是新建的岛屿，我编辑过一次再点就进不去了」
- **现状**：`island-overview` 的 `personNode()` 是纯 `div`，**没有 data-act、没有 click**（真机实测 0/2 可点，点了栈顶不动）——
  上一轮拍板的「总览即配置台（点 char 头像进编辑）」还没落地。「编辑过一次再点进不去」同源：总览上根本没有编辑入口，配置台改完回总览再点还是没反应。
- **结论**：`[可做]` 总览的人物节点可点（char → 档案 / 我 → 马甲），即浮 2 的「总览即配置台」第一步。**拍板：做。**

## 三、外观

### 外1 · 预览改了、实际没改（App 名字颜色）
- **原话**：「配色更改后预览里面正文颜色也改了，但是实际点到那里去看是没有改正文颜色的」「我在预览里看到连app的名字颜色都变了，但是一点到实际的去还是没变的（选择配色的时候）」
- **现状**：真机实测**无壁纸时 App 名颜色跟主题**（`#43382C` → `#E7EFE8`）；**铺了壁纸就不跟** ——
  `style.css:6960/6981` 的 `.is-dark-wall/.is-light-wall` 把 `.w-app-name` 等写死成 `#F2EDE3`/`#4A4238`（壁纸对比度优先），而预览容器没有这两个类 → 预览说谎。
- **结论**：`[可做]` 壁纸下的字色改成**按主题着色但保对比**（每个主题块出一对 `--wall-ink-on-dark/on-light`），预览同步用同一对变量，不再说谎。

### 外2 · 正文颜色写死
- **原话**：「正文跟着主题，气泡有角色设置的话跟着角色设置」
- **现状**：聊天气泡 `.msg-user/.msg-assistant .msg-text{color:#2A2118}`（style.css:1145/1149，当年为修「浅字浅底隐身」写死）；朋友圈 `.moment-text{color:#1A1A1A}` 等一整组微信色。**且夜灯主题下角色气泡 = 深底配深字，看不清（真 bug）**。
- **结论**：`[可做]` 气泡正文 → 有角色设置用角色的，没有跟 `--g-ink`（夜灯自动变浅字）；朋友圈正文跟主题。

### 外3 · 组件和 App 不能跨屏移动
- **原话**：「目前组件和app还不可以跨屏幕移动喔」
- **现状**：`page-desktop.js` 拖拽全程锁在起点屏：`canPlace(d.pages, st.pi, ...)`(2261)、`persistCell(ctx, st.pi, ...)`(2294) —— `pi` 从没变过。桌面实际有 4 屏（perPage [1,9,5,10]）。
- **结论**：`[可做]` 拖到屏幕边缘换页，落到目标屏。
