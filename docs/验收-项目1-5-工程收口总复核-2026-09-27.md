### 1. 统一字段含义（均已核实）

| 字段 | 含义 | 出处 |
|---|---|---|
| `sandboxId` | **岛章**。所有主表记录（characters/userMasks/chats/moments…）与向量块都盖此章；值=写入时 `scopeId()` | core.js:436 `scopeId`、:72 `tagScope`、memory-vec.js:1176 建块 `sandboxId:sid` |
| `charId` | 向量块上的**「哪个大脑」**，已过 `rootOf` 归一（=大号 id），不是产出脸 | memory-vec.js:903 forgetHit（charId 过 rootOf）、建块七处 |
| `rootId` | 主表记忆档案 `charMem:<root>` 的门牌 = 大号 id | page-memory.js:156 `charMemKey` 过 rootIdOf |
| `fromCharId` | 向量块上的**「哪张脸产出」**（精确，不过归一） | memory-vec.js:904/908 forgetHit、建块四处 |
| `userId` | user 马甲 id；向量 `user:<uid>` 池 | core.js:757 findUser、memory-vec.js:237 userKey |
| `groupId` | 群 id；向量 `group:<gid>` 池 | memory-vec.js:224 groupKey |

> 铁律（memory-vec.js:951-956 注释）：删除角色**必须按 `fromCharId`（产出方）**删，不能按 `charId=rootOf`（会误清同 root 整池）。项目4 的 `forgetCharSet` 正是按 fromCharId 集合精确命中。

### 3. 删除事务顺序（五项目一致）

```
① 确认对象存在（findSandbox/findChar/findUser/findGroup）
② 跨岛/引用守卫（purgeGuardReferenced / user maskIds 跨岛引用）

```
