## 2. 数据模型（ta-life.js 头注释为准）

- **taItems 事项**：title*、detail（阻碍/说明）、status（**五态闭集**：进行中/受阻/待核实/暂停/已完成）、nextCheck（下一复核条件）；
- **taPromises 承诺**：quote*（原话）、toWhom、condition、standard（完成标准）、evidence（当前证据）、pendingWhy（待核实原因）、status（四态闭集：待核实/已兑现/未兑现/已解除）；
- **taFollows 关注**：target*、reason、latest（最新已知信息）、note —— **没有完成态**（关注过期 ≠ 完成，设计稿红线）；
- 公共字段：`id, sandboxId(tagScope 盖章), refCharId(**归 root**，皮套与大号同一段生活), refUserId, sourceType, sourceId, sourceRef, history[], createdAt, updatedAt`；
- 纪律四件套：DEFAULTS 登记 / 删房名单 / tagScope 盖章 + 全量 set / scoped 读取（跨岛 id 用 findInScope 挡死，page-collection 同款）。
