# 功能勘察汇总 — 2026-10-06

> 用途：给《小岛指南》App（page-guide.js）提供**有依据的**功能清单。
> 来源：4 组并行只读勘察（聊天群组域 / 世界角色域 / 设置工具域 / 桌面组件域），
> 逐条对着真实代码核过，不编造。
> 维护：新增或下线功能后回来改这里 + 改 page-guide.js 的 SECTIONS。

## 一、新手必看：配置顺序（最高优先级）

**必配**（不配就完全不能用）：
- **主 API**（设置 → 主 API）—— 唯一硬性必配项。填「接口地址 + 模型名」（Key 可留空，部分中转免鉴权）。
  不配 → 所有对话请求失败，角色不回话，心跳/日记/朋友圈/主动消息全部连带不可用。
- **造一座岛 + 一个角色**（浮岛）—— 数据层前置，配好 API 仍不能直接对话。
- **数据与备份**：全部数据只在本机浏览器，换设备/清缓存即丢，第一次建议导出一次。

**选配**（不配只是少一个功能）：
- 副 API —— 备用通道 + 后台任务。主挂了自动轮询到它。不配对话仍正常，只是没容灾。
- 总结 API —— 记忆抽取用的便宜模型。**不配会跟随主 API**。
- 向量记忆 API —— **不配不回落**，向量记忆整个不开（不会偷偷用主 API 发 /embeddings）。
- 生图 —— 不配则聊天生图、日记/朋友圈配图都不可用。
- 语音 TTS —— 不配不影响任何其他功能。
- MCP 连接 —— 不配就没有工具调用。
- 天气感知 —— 不配角色不知道你现实天气。
- 链接解析 —— 不填 Key 也有匿名额度 5 次/天/IP。

**依赖链**：
```
主 API（必配）
 ├→ 副 API（选配；主挂了轮询兜底）
 ├→ 总结 API（选配；不配跟随主）
 ├→ 向量记忆 API（选配；必须自己填 embedding 模型，不能复制副 API）
 ├→ 生图（选配；贴纸工坊「生成整版」依赖它）
 └→ 语音 TTS（选配）
天气感知 key → 独立    链接解析 key → 独立
MCP 服务 → 逐工具开关 → 每对话「MCP 工具」开关（三层全开才生效）
```

## 二、聊天与群组（page-app / page-chat / page-moments / page-switch / page-group / page-offline / page-phone / page-proactive / page-summary / page-heartbeat）

**聊天 App 4 Tab**：消息 / 通讯录 / 朋友圈 / 我。非消息 Tab 时返回先切回消息 Tab。
- 通讯录是只读的（点谁进对话；加人/改认知/建小号回浮岛）。

**私聊功能点**：
- 气泡长按菜单：表情回应 / 引用 / 复制 / 转发 / 收藏 / 编辑 / 多选 / 删除；条件项：撤回（纯文字，掷骰决定 TA 看到，概率在设置里调）/ 留在灯上 / 朗读·重读。
- 输入区：加号 · 输入框 · 爪印发送。发送键两义：有字=发一条，空着=让 TA 开口。
- 打字浮出表情推荐条；情绪印章（输入框内印章钮，跨天自动取消）。
- 加号面板 8 项：发照片 / 发文件 / 转账 / 拍一拍 / 生图（我发 or 让 TA 发，TA 可拒绝）/ 查岗（40% 被察觉）/ 日记 / 翻译。
- 角色可撤回（[撤回:N|原因] 协议）、表情（[表情:]）、拍一拍（[拍一拍:]）、生图（[生图:]）、HTML 小游戏（TA 送可玩网页小游戏，结算回喂）。
- 顶栏：线下模式（门）/ 搜索聊天记录 / 对话设置；点角色名字直接跳朋友圈。
- reroll（重掷）、重画（TA 发的图）、语音条、翻译对照、表情回应药丸、停止。

**朋友圈**：刷新=催更；发一条（四选一，长按=纯文字）；微信式封面（点=换壁纸，长按=贴网址）；赞/评论可选身份；评论可发表情包、可回复；可见性三道闸（账号隔离/朋友权限/四档范围）。

**「我」那一屏**：个人资料 / 切换账号（只列当前岛）/ 钱包 / 表情包 / 拍一拍后缀 / 设置。各项属当前账号（表情包是唯一能同步到所有岛的）。

**系统级切号**：时空切换器（降落岛→选马甲→选角色），整机重绘。面具轮盘（长按输入框左侧头像呼出，宇宙内切皮套，切换后插系统事件「你换了一副面具」）。

**对话设置（角色设置）**：聊天（预设/MCP开关/主动消息/撤回概率/现在评估一次）/ 朋友权限 / 记忆（开关·整理模型·整理聊天记忆）/ 他的手机（自主生活四档·查手机模型·锁屏密码）/ 个性化（聊天外观·语音·指定模型）/ 数据管理（导出对话·删除角色）。

**群聊**：建群三步（选发起账号→选成员按本体分组→群资料+开场方式）；群消息页顶栏（多人线下/搜索/详情）、长按头像=快速@、打@弹提及面板、左滑引用、长按自己撤回、长按别人留灯；群详情（改名/群头像/成员/整理群记忆/美化CSS/邀请/退出/群聊设置三档自动续聊）；**没有踢人按钮**（只能自己退出）。群记忆阈值触发总结（≥30条/≥6000字/跨3活跃日）。

**线下模式**：不是独立 App，从聊天顶栏门图标进。与普通聊天区别：普通一来一回气泡，线下是叙事流（场景框+你的行动+角色台词+建议选项+环境更新）。可设壁纸/交互/语言/记忆/叙事镜头/文风七档。多人线下加：叙事焦点（群像/指定角色）、局部重写上一轮、在场管理（暂时离开/在路上）。

**查手机**：0 API（内容要么镜像真实数据要么读本地表）。能看：消息/淘宝订单/健康打卡/备忘录/浏览器/相册（空态）。四种解锁路径（宽限期直进/他没设密码/你记得的密码/只看一眼）+风险轨迹条。

**主动消息**：候选来源（关注/悬而未决/想说没说/角色推进计划）→ 闸门筛（开关/免打扰时段/次数/冷却/暂缓间隔）→ 模型判 decision=send。触发时机（回聊天列表/每轮回复后节流2分钟/手动「现在评估一次」）。

**总结引擎**：按累计活跃量触发（≥30条/≥6000字/跨3活跃日），user 主权优先（op=add且确认=active，其余pending）。

**心声**：角色没说出口的心里话，跟主回复一起出（不额外花钱）。点名字/头像看，两页（最新/历史）。

## 三、世界 / 角色 / 创作（page-island / worldbook / ta / diary / memory / calendar / gallery / wj）

**浮岛**：孤岛（只住 1 人）/ 群岛（多角色）两种房型。存档列表（可拆岛，会逐项列出跟着没的）；岛屿总览=唯一配置入口（五段：核心成员/NPC/角色档案/群岛关系/入口）。大号/皮套/马甲/NPC 四种身份各有归属。

**世界书**：两级（书→条目）。书分全局/个人。条目两种注入（常驻 or 关键词触发，关键词子串命中即召回，私聊最多取10条）。群聊注入按知情范围分流（个人书只进挂靠者，挂在群外的整本不注）。导入/导出（Word拒收、酒馆格式拒收、有模板）。

**ta 生活窗口**：首页四区（此刻/最近在做/一直留意/身边的人）只读 0 模型。三张表：事项（五态，进行中/受阻/待核实/暂停/已完成）、承诺（四态，**绝不自动判兑现**只能人工确认）、关注（无状态机）。模型提案三模式（candidates/review/advance）+四道校验+硬性禁令（不准提死亡结婚等重大变化、不准无证据标已完成、事项完成≠承诺兑现、不准替 user 做决定）+高影响二次确认。关系网双视图（图/列表），**只画有依据的边，不虚构连线**。

**记忆（留痕）**：六格分类 + 整理三格（待确认/最近更新/已归档）。手动加 vs 自动整理，来源三字段不可改。状态闭集（有效/待确认/已标错/已替代/已归档）。向量检索是候选生成器+重排（不是纯相似度取前几），四种归属池（角色/群/岛/账号）。

**帷境**（8 页）：私人剧本档案馆。开帷五步（取景→出场人物→现实→取材→试读）。剧本详情 5 tab（概览/章节/分支/版本/成稿检查）。成稿检查本地 0 API 五层（人物逻辑/禁用/高频/句式/段落）。同席共读三视图（邀请票→四回应→台账），**只有 accept 才进同席**，结束时产生一条「共同读过」现实候选。谢幕五路独立（收藏≠分享≠共读≠定史）。正史审阅四步硬闸门（候选事实→冲突确认→人物认知→写入），幂等。

**日记**：列表+写日记（让 TA 写 / 我自己写）+设置（6 种壁纸·4 种信纸·每天几点自动写·配插图）。自动日记存「每天几点+写到哪天」，打开时比对补算（不是 setTimeout）。

**日历**：月历主页+新建+详情。三类事件（我的提醒/邀请他/共同事件/纪念日）。公共日期数据包（法定假期/调休/文化节日，按地区）。设置六组。**时间撞了不自动覆盖**，弹窗问。

**相册**：与照片墙同一份数据。群岛每角色一本不混。按天分组。早期没记归属的单独一截。自动压 1280px 只存本机。

## 四、设置 / 配置 / 外观 / 工具（page-settings / subapi / singleapi / tts / imggen / mcp / backup / appearance / widgetstore / workshop / stickers / wallet / presets）

详见「一、新手必看：配置顺序」。

**主 API 表单**：备注名/地址/Key/模型名（可拉取 /models）+ 生成参数（温度0-2/上限64-32768/上下文2-200/超时60-300s）+ 流式/启用/当前使用 + 测试连接（ping，不保存即可测）。

**外观**：4 套配色（纯白/夜灯/蜜桃/海盐）+ 5 种壁纸 + 4 种 App 图标风格 + 桌面体验（文字大小/动效）+ 正文字号字体颜色（始终全局）。草稿-保存模型。可按岛覆盖。单独改 App 名称/图标子页。角色聊天外观（对话设置→外观）三预设（默认/企微/捡手机）+ 壁纸/气泡/颜色/排版/CSS 高级自定义。

**组件商城**：橱窗卡（加到桌面/在桌上×N/移除/再摆一件/设置）。自制组件编辑器（HTML+CSS，实时预览，变量白名单 time/date/weekday/weather/photo/lampNote/charName/todoCount/countdown）。删过的组件原位装回。

**工坊**（page-workshop）：六类记录型模板（日记/打卡/收藏/进度/档案/时间线），装给角色手机。**注意：贴纸工坊和自制组件都不在这里**（贴纸工坊在收藏馆，自制组件在商城）。

**表情包/贴纸**：导入 txt/csv（每行一条）、选本地图、分组管理（改名/同步全局）、聊天里按组发、打字推荐。贴纸工坊五步（选脸→套系→生成整版→3×2切片去背景→归属入库），归属三态（角色单人/双人CP/我的需勾选同步）。

**钱包**：余额自己填；流水扫对话里的转账消息（不单独存表），点流水跳回那段对话。

**预设注入**：引擎开关 + 五种调用类型 + 线上/线下注入序列（每行显示槽位号/tokens/可选）。内置卡上锁（用户看不到内容）。自定义注入卡（标题/正文/群聊可用开关）。

**拍一拍后缀**：「我」页设置，默认「肩膀」，只写后半句，存当前账号。

**数据与备份**：导出 .json（含 Key）/ 导入（覆盖）/ 存储空间 / 图库占用 / 清除全部数据。**图片不在备份里**（在图库 IDB）。

## 五、桌面组件域（page-desktop / app / core / page-app / page-collection / behavior-text / msg-trans / msgcenter / splash / store）

**桌面形态**：4 屏横向滑动（每屏 4 列 × 6 行 = 24 格），原生 scroll-snap。首屏落在第 1 屏（主屏），负一屏要往左滑。页码点 4 个随滚动高亮。底部 Dock 常驻三入口：聊天 / 世界书 / 设置。组件位置数据化存在 store，按岛覆盖 > 全局。单个组件渲染炸了只落空壳，不整屏白屏。

**四屏各有什么**：
- **第 0 屏（负一屏）**：照片墙（占满整屏，电影胶片拼贴：场记板+胶片条+8 格相框+纸带）。点空相框加号=加照片。与相册同一份数据。
- **第 1 屏（主屏）**：日期头（4×3，含时段问候 + **PULL TO CHOOSE 坠子**，点它或下拽>24px 拉开选人/切号）+ 世界书/组件商城/浮岛/外观（第4行四格）+ 聊天/设置/夜间模式（第5行）+ **帷境通栏**（4×1，衬线字「帷境 / 今晚，想读哪一种可能？」）。
- **第 2 屏**：挂件灯（4×4，3D 亚克力灯，可拖动旋转/双指缩放，点卡片浮到全屏放大态；**必须走 http，file:// 下点不亮**）+ 预设/工坊/查手机/留痕（第5行四格）。第5行以下是翻屏手感区，别排满。
- **第 3 屏**：音乐卡（4×2，**纯装饰无真音频**）+ 待办（2×2）+ We/小岛指南/日历/ta/相册/外观/组件商城 + 空壳格（贴纸/组件商城空壳，不跳转）。

**桌面编辑态（长按 420ms 或长按空白）**：
- 只给当前屏加网格底纹 + 组件可拖；进态震动 12ms。
- 编辑态内单击直接起拖（不用再长按），跟手放大 1.06 倍，幽灵格显示落点（放不下变红）。
- 落点吸附按中心点算（保证最边一格够得着，同 iOS）。支持**跨屏拖**（拖到边缘 46px 内翻屏）。
- 删除=编辑态每组件左上角小叉叉，二次确认，**留在编辑态**方便连删。删掉的记进 `desktopRemoved`，组件商城「你删过的」可**原位装回**。
- 点空白处退出（用 click 不用 pointerdown，避免拖动误退出）。

**系统级能力**：
- **时空切换器（切号）**：两条入口（桌面坠子/角色卡点头像）。两段：切换岛屿（降落）+ 这座岛里的身份（我 的马甲 + 对面角色的大号/皮套）。桌面下拉选段是另一条降落路径（垂下一叠岛卡，群岛先展开手风琴选人）。
- **面具轮盘**：长按聊天输入框左侧头像呼出，点一下即切（滑动难做准故改点击）；切换后插系统事件「你换了一副面具」。⚠️ 入口在 page-chat.js 里没验到（见拿不准）。
- **夜间模式**：主屏 mode 格，点一下切 night↔grape，与外观 App 共用。
- **边缘右滑返回手势**：只认左边缘 46px 内右滑，滑过 72px 触发；竖向滑动优先不抢列表。
- **返回三重语义**：页面可自己接管（聊天停在朋友圈时返回先切消息 tab）/ 已在桌面按返回补基线历史不退出浏览器 / 700ms 重入锁防连点弹飞。
- **报错卡**：所有 err 升级成卡（真实原因标题+稳定错误码+技术细节+×关闭+复制报错），**不自动消失**；错误码 CFG/HTTP/TIMEOUT/NET/PARSE/APP-xxxx；网址统一过闸（品牌域+localhost 抹掉）。
- **启动页 splash**：全屏夜色，十六句诗浮现退场→「爱」→天亮→sleepy浮现，约 9.5 秒自动淡出不用点；点任意处提前结束；`?splash=0` 或「减少动效」不播。

**收藏馆（page-collection）**：We 空间三个主页面之一（首页/时光/收藏馆）。门厅有封面+计数条+贴纸工坊入口+待确认条+藏品卡（七类：票根/照片/信件/音乐/礼物/地方/其他）。来源实时复核（来源失效明确提示，绝不静默入馆）；pending 不算进正式馆藏计数。**不占桌面格**，只从 We 首页「去收藏馆→」进。**We 内不提供切岛入口**。

**behavior-text.js**：冻结的行为文本包（十模块/五场景闭集）。**用户看不到也用不到**——不读配置不读存储不发网络，纯函数进 prompt 的 system 槽；是「预设」配置链路的底座。⚠️ 文件头「未接入」注释与代码矛盾（实际 prompt-engine 在读），用户视角无入口。

**消息翻译（msg-trans）**：线上私聊气泡/线下 dialogue 段/群线下台词共用一份实现。两道闸门（全局开关 + 「他说的话跟你不是同一种语言」，中文角色永远不长）。展开只有译文（无标头），收起只留「译」字标。点译文本身收起/展开。收起不落盘。**入口**：线上私聊加号面板「翻译」toggle、线下设置「他说的外语附译文」。他说不说外语由「常驻地点」推出，不由开关决定。

**消息中心（msgcenter）**：独立于页面栈的通知中心。顶部横幅「XX 正在输入⋯」（多人显示「还有N位」，点横幅跳进会话，120s 保险防卡死）；新消息弹窗（头像+名字+48字摘要+查看，5.2s 自动消失，同一时刻最多 3 张）。**正盯着这个会话就不弹不挡**。

**数据存储与删房**：
- 文本数据→localStorage（前缀 sleepy.v1.）；空间满给人话提示不静默丢。图片/文件→IndexedDB（只留 mediaId 引用，读取用 blob URL；无痕模式自动退回 dataURL）。
- **删房（拆岛）会清**：房本身 + 约 40 张按岛章过滤的整批表（聊天/记忆/照片/日记/待办/收藏/角色大号皮套NPC/朋友圈/钱包/表情包/群三表/查手机十张表/日历/行动请求/ta 四表/灯留言/自制组件/慢递…）+ 会话 id 动态键（htmlGameResult）+ 岛级覆盖层 + charRel:<sbId> + 悬空引用 + 向量库（清失败整体中止）。
- **不随房删**：用户创作的模板资产（wsTemplates 是全局创作资产）。
- 删角色时挂它名下的 NPC **不连坐**，改由 cleanupChar 收编归岛。
- **换设备**：设置→数据与备份→导出 .json（新设备导入会覆盖）。**图片不在备份里**（在图库 IDB），要重新传。导入有回滚链，回滚未完成时快照置顶可续处理。
- 存储空间满时所有人话提示「本地存储空间已满，请先导出备份再清理数据」。


## 六、勘察中发现的、需要修正/注意的点

1. **page-guide.js 里「工坊」的描述写错了**：写成「贴纸、自制组件、装到角色手机上」，但代码里工坊只做六类记录型模板；贴纸工坊在收藏馆，自制组件在组件商城。→ 待修正。
2. **ta 首页不是 tab 布局**，是四个编号区块（01-04）；tab 化的只有关系网（图/列表）和剧本详情（5 tab）。ta 的各详情页是平级注册页面。
3. **群聊没有踢人按钮**（只能自己退出），也没有转发功能。
4. **向量记忆 API 不配不回落**（不会偷用主 API 发 /embeddings）——这条和「总结 API 不配跟随主」不同，手册要分开写。
5. **记忆系统的认知标签（aware/unaware/single）实际存在浮岛认知锁的 charState 里**，不在记忆表里；prompt-engine 翻成五种意识模式。
6. **查手机的「相册」是空态**（有壳没内容），且查手机**没有账单/钱包类 App**。
7. **副 API 实际既是容灾又是后台任务**（api.js 把它放进所有对话候选队列），但设置页文案只说「后台任务·备用通道」。
8. **「激活与设备」是灰占位行**（点不动，标注 2.19 激活码）。
9. **群聊搜索有两个入口**：群消息页顶栏真能用，群详情页那行是占位（点了提示「已预留」）。
10. **收藏夹页（favorites）注册了但聊天 App 顶栏没有入口**（消息 Tab 顶栏只有 +），可能是断链或从别处进——待确认。
11. **预设注入的「视觉层」与生图「试一张实验区」是两套独立设置**，互不影响。
