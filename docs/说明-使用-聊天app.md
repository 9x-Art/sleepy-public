# 三. 聊天

> 🙌 聊天功能很多，这篇挑复杂的说~ 常规收发一眼就会，就不啰嗦啦！

## 1. 先知道的几件小事

A. 输入框空着直接点发送 = 让 TA 先开口，冷启动救星~

B. TA 的长回复会自动拆成好几条气泡、按打字节奏一条条蹦出来，不是卡了喔

C. Enter 发送、Shift+Enter 换行

D. 消息列表里**长按会话**：置顶 / 改备注名 / 删除对话

## 2. 加号面板（输入框旁的 +）

| 条目            | 是什么          | 要注意的                                                                     |
| ------------- | ------------ | ------------------------------------------------------------------------ |
| 停止            | 掐断正在生成的回复    | 只在等回复时出现，平时不占位                                                           |
| 重说            | 最后一条回复重新生成   | 不满意就点它，不扣额外的额度说明见对话设置                                                    |
| 发照片 / 视频 / 文件 | 发本地文件给 TA    | 走系统选文件框                                                                  |
| 转账            | 转账给 TA       | 单笔上限 99999，备注点卡片可看全文；钱包 App 有流水                                          |
| 拍一拍           | 拍 TA 一下      | 对话里出灰字提示                                                                 |
| 生图            | 生成一张图        | 要先去 设置→生图 配接口！还需要主 API 来想画面                                              |
| 查岗            | 让 TA 汇报此刻在干嘛 | 同样要生图接口 + 主 API                                                          |
| 文字麻将          | 和 TA 开桌 1v1  | 牌局直接在对话里打                                                                |
| 反查手机          | 让 TA 偷看你的手机  | 要在对话设置里开「反查手机」开关；TA 同不同意看他自己的倾向~群岛里 char 反查能看到你和别的 char 的对话喔（当海王需要管理能力！） |
| 日记            | 打开日记         | 直达                                                                       |
| 翻译            | 开关：显隐外语译文    | TA 的常驻地点只说中文时这项是灰的，语言由地点推，不是手动切换的喔                                       |

⚠️ 表情包入口在输入框里的笑脸钮；面板里没有红包和语音~

## 3. 气泡怎么摸

**A. 左滑 = 引用**  
任意气泡往左一滑，输入框上方出现引用条（「我：…」/「TA 名：…」），接着打字发送就行。引用条上的 × 是取消。发出去后引用以小字挂在你的气泡里，TA 也会引用你的话~

**B. 长按约半秒 = 消息菜单**

- 顶部一排 emoji：快速贴个回应
- 引用 / 复制 / 转发 / 收藏 / 编辑：常规操作
- **留在灯上**：把这句话挂到桌面挂件「灯」上，回桌面就能看见
- **TA 的自察**（条件项）：看 TA 对这段对话的内心自察
- **多选**：进去后**点击气泡**就是勾选，可逐条转发 / 合并转发（合并后是一张「聊天记录」卡）/ 批量删除
- **撤回**：只有自己发的纯文字能撤

**C. 点自己头像 = 情绪印章**  
一个心情章直接盖进对话，**跨天自动失效**~ 纯章的消息是印章气泡。

**D. 点 TA 头像 = 心声**  
TA 没说出口的心里话！有新心声时头像上有呼吸光点（雾蓝色的小点点）。

**E. 关于撤回的小心机**  
TA 撤回的消息你看不看得见原文是有概率的，默认 40%，滑条在对话设置里。TA 的撤回显示成灰字条，点开能看内容和原因。

## 4. 搜索聊天记录

顶栏放大镜进入：

A. 空态是分类网格：图片与视频 / 文件 / 链接 / 语音 / 转账 / 表情包 / 小游戏 / 带引用，每类带条数

B. 打字即全文搜（上限 50 条）

C. 点任意结果会跳过去并**闪烁 1.6 秒**，顶部还有本对话的概览（总条数 / 时间跨度 / 最近一条）

## 5. 语音（TTS）

A. 语音条是 **TA 主动发的**（角色配了语音就可能在合适的时机发），不是你录音喔

B. 点语音条播放/暂停，旁边「文」小钮切换文字稿显隐

C. 前置两道：**设置→语音 TTS 总开关** + **该角色填了音色 ID**，缺了会有 toast 提示去哪配

D. 语音不可转发~

## 6. 线下模式（叙事流）

聊天顶栏的门图标进入，弹「**新的 / 继续上次**」。

A. 区别：线上是一来一回的气泡；线下是**叙事流**——场景框 + 你的行动 + TA 的台词 + 建议选项，可以另设壁纸、文风、镜头

B. **暂停或结束都会交接回线上**：线下发生的事会转录（最多 3 条）进对话，TA 下一轮线上回复记得刚才发生了什么，不用担心断层~

C. 前置：对话必须已绑定角色，没绑会 toast 提醒

## 7. 群聊

A. 消息页顶栏「新建 → 发起群聊」，三步：发起账号 → 选成员 → 群资料

B. **长按成员头像**快速 @；左滑引用、长按菜单在群里一样能用

C. 群详情可改群名 / 头像 / 成员 / 邀请 / 退出；**没有踢人、群聊不支持转发**喔

D. 群记忆会自动总结（≥30 条或 ≥6000 字或跨 3 个活跃日时触发），不用手动操心

## 8. 对话设置（顶栏齿轮）里值得点开的

A. **主动消息**：TA 可以自己先开口！可调节奏，还有「现在评估一次」手动触发

B. **聊天外观**：classic / 企微 / 捡手机三套皮肤

C. **撤回被看到概率**滑条：默认 40%

D. **朋友权限 / MCP 工具开关 / 查手机档位 / 记忆整理模型 / 角色语音**：都是按对话独立配的

E. **导出对话**：纯文本导出

F. 清聊天记录没有独立入口，全局备份走 **设置→数据与备份**（导出 .json，⚠️ 图片不包含在内！）

## 9. TA 侧的「演出」速查

这些不是你操作的，是 TA 自己的行为，看到别慌：

- **TA 发的图**：TA 自己生的，点开可以**重画**
- **灰字「撤回了一条消息」**：TA 撤回了，点开看内容+原因
- **小游戏卡片**：可玩！支持全屏，结算结果会回喂给对话
- **「慢递」信**：TA 写的延迟信，到时间才送到
- **TA 换了头像**：TA 自己换的（也可能是在反查手机看到你和别人的情侣头像后…出点小事 www）
- **收藏提议卡**：TA 提议把聊到的时刻记进收藏馆

| 想用                   | 得先有               |
