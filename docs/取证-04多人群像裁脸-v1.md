## 四、归因分类（按证据强度）

| 假设 | 结论 | 依据 |
|---|---|---|
| 保存裁切 | **排除** | media.put 原样存 blob，无任何转换 |
| 请求内容漏词/混词 | **排除**（限本轮可查范围） | 描述词/人物块/结构词逐字在，无双人与近景词混入 |
| 请求参数问题 | **部分成立（chat 通道）** | chat 正文无任何尺寸/比例表达，比例完全由服务端模型自定；general 通道有 size 字段但默认方形 |
| **显示裁切** | **确证存在**，是否能解释用户的观察**尚不能定因** | 预览 square+cover 非方图必裁，且实验区无看原图入口；但历史原图缺证，不知道用户实际图的宽高比、也不知道用户从哪个界面看到的「裁脸」 |
| 原始生成构图问题 | **不能排除**（模型在方形里画 4 人，脸被自身构图裁掉的可能真实存在） | 同上，缺历史原图 |

**一句话**：显示层确实有一道必然的裁切机制（square+cover，且无处看原图）；但「用户看到的裁脸」是这道显示裁切、还是原图本身构图裁切（或两者叠加），**证据不足，尚不能定因**。
