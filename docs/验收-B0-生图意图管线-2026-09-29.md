## 改了什么

### imggen.js
- 新增 ImagePlan 契约：`normalizePlan` / `subjectTextForPlan` / `subjectForChar` / `subjectForUser` / `parsePlanJson`（附 `PLAN_SENDERS/CONTENT_TYPES/SHOTS` 白名单）。
- `buildPrompt`：带 `opts.plan` 走新函数 `buildPromptForPlan`——`hasPeople` 只看 `subjects.length`；只有「无人 且 contentType 是 scene/object」才允许 `BUILTIN_SCENE`；身份段（性别+锁脸，多主体带名字绑定）整段进 core **不去重**，去重只发生在 description+extras。

### page-offline.js（doGenPhoto）
- 三键全部显式传 plan：scene（无人）/ char→person+char 锁脸（shot full）/ together→mixed，subjects=[user 马甲, char]（shot group）。env 照旧进 description。

### page-group-offline.js（genScenePhoto）
- plan：mixed / shot group；subjects=present && !away 参与者（char/npc 各带真实 ownerId）+ user（`userIdentityAccountId` → 回落岛卫兵）。description 去掉了与在场者矛盾的「无人物特写」。

### page-chat.js
- `directorAsk` 三段指令改吐 `{description, contentType, shot, subjects, caption, refuse?}`；解析白名单收口；模型没按新格式答 → `legacyFallback:true` 回退旧 subject 逻辑，页面不报错。
- 新增 `planFromDirector`：subjects 字符串→真实实体（char 带 id/锁脸/性别，user 带会话马甲），sender 按业务填（查岗/我发=user，TA 发=char）。
- `runCheckin`/弹层 `doGen`/`doSend`/`redrawPhoto`/`genAndDeliver`/`charSendPhoto` 全部接入 plan；plan 存进消息（`msg.plan`），重画按 plan 重画；老消息无 plan 走 legacy（不迁移数据）。

### moments-ai.js / page-diary.js
- [图] 指令改教 JSON；`[图]` 截长 120→240；配图时 `parsePlanJson` 优先，解析不动走 legacy（原正则猜 shot + 默认锁 char）并标 `legacyFallback`。
