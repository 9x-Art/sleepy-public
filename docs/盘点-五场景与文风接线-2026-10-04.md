## 零、一句话结论

**行为文本（`behavior-text.js`）只接了两个场景：私聊线上、私聊线下。**
其余三个场景（群线上、群线下、主动消息）**各自走独立的老卡**，
`S3`/`S4`/`S5` 三段正文**早已写好但无人调用**。

「六套文风」与行为文本**完全是两套东西**，且现状是 **3 套 + 自定义**，不是 6 套。

## 一、行为文本的五个场景计划（全部已定义）

`behavior-text.js:54-60`：

```js
var PLANS = Object.freeze({
  online:     ['B', 'P', 'L', 'E', 'S1'],   // 私聊线上
  offline:    ['B', 'P', 'L', 'N', 'S2'],   // 私聊线下
  proactive:  ['B', 'P', 'L', 'E', 'S3'],   // 主动消息
  groupOnline:['B', 'P', 'L', 'E', 'S4'],   // 群聊线上
  groupOffline:['B','P', 'L', 'N', 'S5']    // 群聊线下
});
```

⚠️ **注意**：`online` 用 `E`（消息体例）、`offline` 用 `N`（现场延续）——
**这五个场景的槽位不是同一套**（`E` vs `N`），而 `shell`/`f2` 是两张不同的卡。

**十段正文（`TEXT`）全部有内容**，`S1`–`S5` 也不例外
（`behavior-text.js:41-52`）—— **不缺正文，缺的是接线**。

## 四、「六套文风」的实际现状（**与行为文本是两套东西**）

### 现状是 **3 套 + 自定义**，不是 6 套

`prompt-engine.js:1527-1537`：

```js
var STYLE_LABELS = { pure_love: '纯爱日常', literary: '沉浸文学', casual: '轻松互动' };
var STYLE_HINTS  = { pure_love: '…', literary: '…', casual: '…' };
```

UI（`page-offline.js:2175-2180`）四个选项：
`纯爱日常` / `沉浸文学` / `轻松互动` / `自定义`。

### 注入点：`prompt-engine.js:1548-1562`（`narrativeText`）

```
- 整体风格：纯爱日常（贴地的日常口语，短句为主；…）
```

- 非 custom → 注入 `STYLE_LABELS[n.style]` + `STYLE_HINTS[n.style]`
- custom → 注入用户手填的 `styleWords`；**没填则回落纯爱日常**

### 与行为文本的关系：**正交，不是替代**

| | 行为文本 B/P/L/N/S1-S5 | 文风 style |
|---|---|---|
| 管什么 | **人物一致性、授权边界、叙事视角、篇幅分配** | **语言质感、句子节奏** |
| 注入位置 | `shell` / `f2` 两张卡（系统级） | `narrative` 槽（叙事设置段） |
| 是否已接 | 私聊线上 + 私聊线下 | 私聊线下 + 群线下（**线上场景没有**） |

→ **接六套文风 ≠ 把六段新行为正文加进 `behavior-text.js`**。
前者是扩 `STYLE_HINTS` 的枚举与 `STYLE_LABELS`；
后者才是动 `PLANS`。

⚠️ 需要你确认：「六套文风」指的是
**(a) 扩 `STYLE_HINTS` 从 3 套到 6 套**，
还是 **(b) 给行为文本加六套变体**？
两者的施工面完全不同。

## 五、盘点中发现的三个待确认点

1. **群线上没有 `f1` / `shell` 的注入** —— 只有 `groupRound`。
   它的「共享外壳」底线（`shell` 卡）**在群线上是缺席的**。
   这是有意设计还是遗漏，需要你确认。
2. **群线下直读 `cardBody`，绕过决策层** —— 意味着
   `user override` 的回退语义在群线下**与私聊线下不一致**。
3. **诊断层只在私聊线下** —— 另两个未接场景即使接了行为文本，
   也没有 `behaviorUsed` / `modules` 可看。
