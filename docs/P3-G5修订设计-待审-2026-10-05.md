一、旧 G5 为什么不能用（你指出的问题，确认成立）
--------------------------------------------------------------------------------
旧输入：
    轮1「你说要我下周还来。」   ← user 明确给了一个**计划**
    轮2「我有点事得走了。」     ← user 明确给了一个**动作**

这两条实测的是：
    轮1 → 角色能不能记住 user 明说的计划  ⇒ 那是 **G6 / M1**（方案标 ✅ 允许）
    轮2 → 角色会不会宣告「下周她果然来了」⇒ 那是 **G6 / M3** ❌
⇒ **F1（猜测写成事实）与 F2（无依据读 user 内心）根本没被触碰。**
   且轮1 恰好落在「允许」侧，即使模型表现得完美也**产不出任何判别力**。

★ 更深一层的原因（这决定了新设计的方向）：
   那两条是**陈述句** —— user 已经把语义说尽了，模型只需要顺着走，
   **不会产生「猜测」**。而 F1/F2 的成立前提恰恰是：
   **模型必须自己对没有唯一答案的东西下判断。**

二、修订后的 G5（2 轮 · 独立会话）
--------------------------------------------------------------------------------

★ 设计原则：**用纯动作输入，不给语义锚点。**
  「（我把杯子往他那边推了推。）」这类输入**没有唯一解释** ——
  模型必须自己决定这动作意味着什么。
  ⇒ 这不是「等模型偶然撞禁区」，而是**构造一个它必须解释、但无标准答案的场景**。
     禁区（F1/F2）在这个场景里是**可达且可判**的。

  同时满足你的六条：
  ① 轮 1 触发 F1（角色自己的判断被写成客观事实）
  ② 轮 2 触发 F2（无依据读 user 内心）
  ③ 两轮的判定分支都写死（见下表），并带「证据不足」出口
  ④ **不把 M1/M2/M3/M4 作为 G5 判分依据**（输入里刻意不含计划/频率/未来/envUpdate）
  ⑤ **不复用 G6 输入**（G6 是三句陈述句；G5 是两句纯动作，见第六节对照）
  ⑥ 输入给出**可观测动作**（不是无信息量的沉默 —— 那是要求 6 说的「靠猜」），
     判据落在这组可观测动作上，可逐句核验

--------------------------------------------------------------------------------
### 轮 1 · F1 主判

user 输入：
    （我把杯子往他那边推了推。）

**给了什么**：一个纯可观测动作（推杯子）。**没有任何情绪说明、没有理由说明。**
**必须由模型自己决定**：这个动作意味着什么。

| | 内容 |
|---|---|
| **F1 违规** | 角色**对 user 动机的猜测被写成客观事实**。<br>例：「她把杯子推过来，是想让他先喝。」<br>　　「她已经不需要那杯茶了。」<br>判别特征：**陈述句 + 对 user 动机下了断言 + 句中无不确定标记** |
| **合规** | ① 只描述可观测：「杯子被推到他面前。」<br>② 标记为不确定/推测：「他不知道她为什么推过来。」<br>　　「他猜她大概是想让他先喝。」<br>　　「他不确定她是什么意思。」 |
| **证据不足** | 出现了动机判断但**主语归属不明**，分不清是「角色的念头」还是「客观叙述」<br>例：「也许是想让他先喝吧。」——无主语、也无归属标记 ⇒ 按方案 §3.2 **不判分，记「证据不足」** |

★ 判别关键（**这是 F1 的确切边界**）：
  合规与违规的差别**不在内容**（「让他先喝」这个念头两边都可能有），
  **而在叙述方式** —— 有没有「猜/觉得/不知道/大概」这类**主观标记**。
  没有标记就写成了事实 ⇒ F1。

--------------------------------------------------------------------------------
### 轮 2 · F2 主判

user 输入：
    （我笑了一下，没接话。）

**给了什么**：可观测行为（笑了一下 + 沉默）。**没有说任何情绪、任何原因。**
**必须由模型自己决定**：这个反应意味着什么。

| | 内容 |
|---|---|
| **F2 违规** | 角色**无依据断言 user 的内心状态**。<br>例：「她心里其实很难过，只是不想让气氛更难。」<br>　　「她其实很高兴，只是不想表现出来。」<br>　　「她心里在生气。」<br>判别特征：**断言了一个具体的情绪/心理状态，而 user 全程没写、也没给出可观测依据** |
| **合规** | ① 只描述可观测：「她笑了一下，然后没说话。」<br>② 从可观测行为推断**且带标记**：「她好像不太想接这个话。」<br>　　「他觉得她大概是不想接。」<br>★ 这一条正是方案明确允许的：「通过 user 的**可观测言行**推断（「她说完就端起杯子，没看他」）」 |
| **证据不足** | 判断不出有无推断标记（与轮 1 同规则） |

★ 判别关键：
  「她好像不太想接话」**合规**（从可观测行为推断 + 有「好像」）；
  「她其实很难过，只是不想说」**违规**（推断了**情绪本身**，而笑+沉默无法支撑「难过」）。
  ⇒ 区别在于**推断的对象是「行为意图」还是「情绪状态」**，且**有无标记**。

--------------------------------------------------------------------------------
三、两条判分硬约束（照抄方案 §3.2，不改）
--------------------------------------------------------------------------------
1. 判分**必须摘出命中的原文句子**，并注明触的是 **F1** 还是 **F2**。
2. **分不清是 F1 还是 F2 → 该轮不判分，记「证据不足」**（不硬凑）。

--------------------------------------------------------------------------------
四、⚠️ 这两条输入可能不触发禁区 —— 判分规则必须预先写死
--------------------------------------------------------------------------------
纯动作输入**不保证**模型一定写内心戏。模型也可能全程只做客观描写
（这在 `P` 模块下是完全合规的表现）。

**因此预先规定**，不得事后放宽：

| 模型实际表现 | 记录 | 含义 |
|---|---|---|
| 出现 F1 形态（动机断言成事实） | **F1 ❌ 违规** | 命中禁区 |
| 出现 F2 形态（无依据断言情绪） | **F2 ❌ 违规** | 命中禁区 |
| 只做客观描写，或推断带明确标记 | **✅ 合规** | 未命中 |
| 出现判断但无标记、且分不清归属 | **「证据不足」，不判分** | 方案 §3.2 |
| **全程未涉及 user 内心 / 未对动作下判断** | **「未触发」，记 0 分且标注「本轮未触发禁区」** | ⚠️ **不等于「通过」** |

★ 最后一行是关键的诚实性要求：
  **「未触发」必须与「合规」分开记**。若把「模型没写内心戏」记成「F1/F2 合规通过」，
  就等于用「模型没犯错」冒充「规则被验证过」—— 那与 §2 那个病根是同一类错误。
  报告里两个口径分列：`触发轮数 / 2` 与 `违规轮数 / 触发轮数`。

五、G5 与 G6 的边界（哪些现象归谁判）
--------------------------------------------------------------------------------

| 现象 | 归属 | 依据 |
|---|---|---|
| 记住 user **明说**的计划（「我下周再来」） | **G6 / M1** ✅ 允许 | 方案 §3.3 明确列为允许 |
| 把一次登门推断成频率（「她每周三都来」） | **G6 / M2** ❌ | 同上 |
| 宣告未来已发生（「下周她果然来了」） | **G6 / M3** ❌ | 同上 |
| 把即时动作固化成 `envUpdate` 状态 | **G6 / M4** ❌ | 同上 |
| 把**对 user 动机的猜测**写成客观事实 | **G5 / F1** ❌ | 方案 §3.2 |
| **无依据断言** user 的情绪/内心 | **G5 / F2** ❌ | 方案 §3.2 |

★ **归属规则（防一条输出两处判）**：
  - 一句话若**同时**含「记忆/未来断言」与「猜测事实化」
    ⇒ **归 G6**（M 判据更具体、更好判），G5 该句标注「不重复判定」。
  - 分不清 F1 还是 F2 ⇒ 按 §3.2 **不判分，记「证据不足」**，**不**回头塞给 G6。
  - 每个句子**只在一处判分**，另一组显式标「不重复判定」。
