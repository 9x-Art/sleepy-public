# sleepy 🏝️

> 一座装在手机里的浮岛：和角色聊天，也陪他们过日子——有日记、朋友圈、主动消息、心声、他自己的手机和一套会自己运转的小生活。

sleepy 是一个**纯静态前端**应用：没有构建工具、没有框架，原生 JS + 单个 style.css + index.html，双击 `index.html` 就能打开（部分功能需要本地服务器或托管）。数据默认全部存在你自己的设备浏览器里，不依赖任何远程账号。

## ✨ 它有什么

- **聊天**：气泡对话、长按菜单、引用、撤回、生图、语音、文字麻将、反查手机、线下叙事模式
- **TA 会自己动**：主动消息、朋友圈、日记、心声、查手机里的自主生活（购物 / 健康打卡 / 备忘录 / 音乐 / 短信 / 书架）
- **Ta 生活窗口**：事项 / 承诺 / 关注三张表 + 关系网，模型提案必须经你确认
- **留痕（记忆）**：自动整理 + 手动记忆 + 待确认机制 + 可选向量召回
- **帷境**：私人剧本档案馆，写故事、生成正文、邀请角色共读，正史审阅逐条确认
- **以身入局**：导入 TXT 小说世界执行委托的跑团玩法
- **群声**：岛内公共论坛「众声喧哗」；**御膳房**：设定打包分享站
- **桌面**：四屏可编辑、组件商城、自制组件（只做变量替换、不执行脚本）、挂件灯、外观主题

完整功能说明见 [`docs/`](docs/) 下的使用手册（说明-使用-*.md）。

## 🚀 本地跑起来

```bash
# 方式一：本地服务器（推荐，挂件灯等功能需要 http）
node serve.js            # 默认 http://127.0.0.1:5173

# 方式二：直接双击 index.html（大部分功能可用，个别功能受限）
```

聊天、生图等依赖模型的能力需要在 **设置 → 主 API** 里自己配接口地址和 Key（支持任意 OpenAI 兼容网关）。不配置无法聊天，其余本地功能不受影响。

## 🛠️ 改代码的规矩（二改必读）

1. **零依赖静态前端**：不要引入构建工具 / npm 运行时依赖，保持双击能开的底线
2. **改完跑双绿**：`pnpm check` + `pnpm smoke`（104 个脚本，改了运行时文件它们会告诉你哪里漏了）
3. **改运行时脚本必须跳 SW 版本**：`sw.js` 的 `CACHE` 号 +1，文件头写一行跳版本说明，`scripts/smoke.js` 里的 `EXPECTED_SW_CACHE` 同步——不然用户拿到的是旧缓存
4. **常量块排在所有使用点之前**（var 提升 → 顶层求值抛、导出全丢）
5. 改 CSS 变量前先 grep 有没有人在用；本地助手的工作区目录（已 gitignore）别删

## ☁️ 自部署（想架一套自己的）

- 前端托管在 Cloudflare Pages，部署入口 `bash scripts/deploy.sh`（推 `main` 分支即上线生产）
- `worker/` 目录是配套 Worker（授权账密 + 设定仓库），需要自建 Cloudflare D1 数据库和 KV 命名空间，把 `worker/wrangler.toml` 里的资源 ID 换成你自己的；`ISSUE_KEY` 用 `wrangler secret put` 配置，不进代码
- 不需要云也能玩：纯本地功能开箱即用

## 📁 目录速览

| 路径 | 是什么 |
| --- | --- |
| `index.html` / `style.css` / `app.js` | 外壳、全站样式、启动与全局链路 |
| `page-*.js` | 各 App 页面（聊天 / 浮岛 / 查手机 / 帷境…） |
| `core.js` / `store.js` / `api.js` | 数据层、存档、模型请求 |
| `worker/` | 配套 Cloudflare Worker（授权 + 设定仓库） |
| `docs/` | 使用手册、方案、交接与核查记录 |
| `scripts/` | smoke 护栏、check、浏览器探针 |
